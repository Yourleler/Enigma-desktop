# 0.4.0 完整交互工作台

2026-10-25，Mac。该版本把已有项目能力接入实际 Web 交互：输入区模型/思考选择、会话搜索与持久设置、分组工具箱、常用表单、记录选择、操作结果与取消，以及液态玻璃、深浅主题和窄窗口抽屉。

## 行为变化

- 模型目录来自当前本机 Gateway，保留原 Responses 配置和认证，接入实际 Messages 模型；刷新失败保留已有目录。模型与思考级别作用于当前 Pi 会话并持久化，运行中禁止切换。
- 计划、源码/Schema/资料、技能/配方、隔离协作/实验、记忆、观察、环境/浏览器、检查点/恢复、审查和交接/复现都提供实际领域操作，原始 JSON 收到高级选项。
- 原生技能实际展开；同背景新任务自动切换视图且保留源对话。操作请求与结果记录分开，不伪造 Agent 工具结果；原检查、用户要求、版本与未知效果边界保留。
- 文件/服务/配方/子任务的运行结束与验收结果分别展示，取消须完成收尾，恢复/设置与任务派发串行。
- 独立页面模块分别处理布局、样式、客户端、模型目录和领域适配，仍通过公开 Pi SDK，未改内核。

## 使用与验证

运行 `node dist/src/cli.js workbench --memory`，打开输出的本地访问链接。模型目录可在输入区右下角搜索和刷新，设置/工具箱位于侧栏，窄窗口从左上角或输入区 ＋ 打开。[交互说明](interactive-workbench.md)

验收覆盖 143 项原回归与新版协议、浏览器真实文件/服务/技能/合并/恢复，实际 Gateway 两种模型的多仓库读取、原检查、审批、主题和重连，以及独立生产包安装。68 个表单、13 面板、五种宽度与条件字段另有实际审计。证据与截图按当前构建核对，见 [逐项验收](acceptance-0.4.0.md)。零价格兼容元数据不代表免费；当前 Mac 结果不外推到其他系统或全部模型。

原 GitHub Actions 保持关闭；版本没有合并 PR 或公开发布。托管管家、自动回溯、自修复与文档专精仍只研究。
