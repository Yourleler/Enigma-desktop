# 运行观察插件

观察插件按需启用，不更改主 Agent 的工具结果、验收规则或权限。它监听 Pi 的公开事件和 Enigma 的阶段事件，将有界增量事件和原子状态快照写入 `.enigma-next/observations/<id>/`。

## 启用和查询

通过 Enigma CLI 启动：

```bash
enigma-next --workspace /path/to/task agent --observe
```

通过原生 Pi 的已安装插件启动：

```bash
pi --enigma-observe
```

也可仅加载观察扩展：`pi -e /path/to/Enigma-next/dist/src/pi-observer.js --enigma-observe`。没有 Enigma 核心时仍可观察 Pi 的模型、工具和交互阶段，源码/检查证据的细化只来自已有工具结果或领域事件。插件默认不启用，没有计时器、监听后台进程或状态写入。

在另一终端运行：

```bash
enigma-next --workspace /path/to/task status
enigma-next --workspace /path/to/task why-slow
```

`status` 返回结构化 JSON；`why-slow` 返回中文解释。两者都不调用主模型、不排入主任务、不创建工作区配置、不获取操作锁，也不恢复或重放任何操作。同一个任务目录多个会话时，可指定 `status OBSERVER_ID`。默认选取最近出现活动的快照，最多读取 100 个目录；跨会话明确选择 ID 更可靠。

交互式 `/enigma-status` 也能显示同一快照；另一终端的 CLI 查询是主 Agent 卡住或忙碌时的独立入口。

`ask-status '现在卡住了吗？'` 提供确定性的中文自然语言问答。显式 `--explain` 使用已配置 Gateway 对一个有界快照解释，无工具、无主任务控制；默认最多等待 20 秒，超时/取消降级到事实摘要。该调用有独立 max output 预算，仍与主任务共享服务端资源，不默认连续占用模型。

## 能看见什么

- 请求准备后等待模型可见响应、接收响应流、工具开始/结束、命令 PID 和输出活动、用户交互等待、压缩和收尾。
- Enigma 的工作区操作、源码快照、静态阅读、验收耗时，以及真实文件变化/读取/检查通过/计划修订的证据入口。
- 同一版源码被重复读取、相同工具错误反复出现的可解释信号。这些是疑似低效，不能单独证明任务没有价值。
- 观察进程的存在与 OS 启动身份、快照新鲜程度、最近实际事件和最近可回查的证据变化。

主进程存在不代表任务推进；心跳和 token 流不被当作验收成功。等待模型响应时没有服务端遥测，不能分辨排队、网络、prefill 或隐藏推理。静默命令可以正常计算；原观察进程终止或 PID 身份不匹配时，旧活动阶段不再作为仍在执行的依据。

OS 启动身份查询不可用时显示 unknown；它不是操作系统级可靠监督器。旁路无法确认已逃逸子进程的完整状态，也不会基于旧 PID 杀进程。没有开启插件、状态损坏或读取预算超出时明确报告不可用。

持久快照的进程标识、时间字段、状态和值域会重新校验；损坏时间不能被误当成“新鲜观测”。provider 的 HTTP/助手错误与后续请求用于标记重试，未知错误阶段不猜测内部原因。

## 采集成本与边界

内存最多保留 120 条最近事件、300 条待写事件、100 个活动阶段和 80 类耗时统计。事件日志超过约 1 MB 后轮转，保留一份上一代；状态丢弃数量可见。旁路不保存原始模型流、提示词、源码正文、命令 argv 或完整工具输出，必要摘要对已知密钥脱敏，事实引用链接到原有产物。

事件有 150 ms 合并写入和约 1 秒心跳；并发 flush 合并而不积累无限写队列。错误镜像不改变主任务结果。插件在收尾/退出最多等待 250 ms 写入；剩余镜像若未完成，查询可见旧快照并需看新鲜度，不能声称镜像与执行原子提交。

`timings` 来自单调时钟的阶段测量，不同阶段可能嵌套或并行，不能相加当成端到端耗时。`collection.writeMs` 是历史已结束写入的累计时间；本次快照写入成本在下一次快照可见。它用于测量观察自身开销，不代表已获得加速。

受控验证使用实际 Pi HTTP 请求、真实命令与锁、强杀进程、取消、镜像失败、等待确认和文件证据。Gateway 解释也在实际命令仍运行期间验证：返回 phase/PID/耗时、说明静默不代表卡死或有效进展，没有触发主 Agent 回合或修改。真实报告：`<LOCAL_AUDIT_ROOT>/2026-10-25/enigma-next-validation/live-observer-question-final/report.json`。
