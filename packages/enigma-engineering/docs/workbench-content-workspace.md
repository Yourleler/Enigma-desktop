# 0.4.2 内容工作区


## 最终行为

- 右侧顶部保留已打开的代码、资料、计划、审查、产物等标签，以及具体源码/文档。支持关闭、键盘方向切换、展开和收回，重连后恢复当前标签。
- 每个对话最多保存八个标签，仅在标签页 sessionStorage 保存来源描述和选择，正文及模型历史不写入这个缓存。不同对话的标签分别处理。
- 点击“操作”菜单才显示原领域操作。内容列表和正文在右侧阅读区显示；具体正文隐藏分类导航，仅保留标签与阅读操作。原 68 项领域操作继续可用。
- 仓库文件使用原工作区排除规则，每页最多 200 个路径，支持按路径筛选、目录展开和切换仓库。源码按 240 行分页，有行号、内容哈希和变更提示；路径和读取范围由原后端规则校验。
- 资料正文每次打开或重新读取时核对来源、版本和权限。已移除资料不会从旧标签复活；远端抓取资料仍标记远端未复验。可在原来源打开，当前版本不嵌入飞书在线编辑器。
- 产物读取保存字节并提供安全文本预览和原版下载。源码改变不改写保存版本；HTML 作为文本展示，不执行脚本。
- 晚到的响应不会替换当前内容。右侧展开后，中间导航和输入区按实际栏宽调整；窄屏使用现有抽屉。保留 0.4.1 的玻璃、动效和减少动态回退。

未新增 任务型工作台 的协作云空间、需求系统或自动同步，也未把任务计划包装为独立 Spec 平台。本轮只补齐个人工作台已有内容的阅读与切换。
