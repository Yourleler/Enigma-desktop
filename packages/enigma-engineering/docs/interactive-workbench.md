# Enigma-next 完整交互工作台

0.4.2 在 Mac 上提供本地 Web 工作台。Pi 公开 SDK 处理模型、会话、分支与工具循环，界面共用已有领域模块；没有修改 Pi 内核或复制 Codex/DSH/任务型工作台 内部实现。[内容工作区](workbench-content-workspace.md)与[排版动效](workbench-layout-polish.md)列出最新交互与验证。

## 启动

```bash
npm ci --ignore-scripts
npm run build
node dist/src/cli.js --workspace /absolute/path/to/project workbench --memory
```

工作台输出本地访问链接。已有 Gateway 配置可继续使用；`connect gateway` 创建任务级配置，不改 Codex 登录。服务器只监听 127.0.0.1，API/事件流要求 token 并校验 Host/Origin。浏览器从 fragment 接收凭证，后续保存在当前标签页 sessionStorage，不写入请求 URL 或模型上下文。

## 对话与模型

左侧管理项目与对话，顶部进入计划/协作/时光机/运行状态，右侧打开代码/资料/产物/环境。实际工具结果在输入区上方默认折叠。输入区右下角选择权限、模型和思考级别，设置作用于当前会话，通过 Pi SDK 保存到原生记录，重开后保留。运行、压缩、审批或其他操作未结算时，先等待或取消再切换。

启动时读取现有配置，并从已有本机 Gateway 网关获取模型目录。目录当前返回 50 个 Messages 模型，另保留原 Responses 默认模型；名称、模型 ID、上下文与输出限制来自真实目录。可搜索 GPT、Claude、DeepSeek、Gemini 等系列。刷新失败保留已有模型；未配置模型不会假装可用。

目录中的 `claude-*` 是网关广告的兼容 ID，不意味着都使用 Claude 模型；实际模型系列以显示名称为准。目录未提供真实价格，SDK 的零成本兼容值不代表免费或实际费用。思考级别按模型支持范围列出，使用网关的 effort 参数，不能只改变界面文字。

设置可切换浅色/深色/系统主题、玻璃和动效；高级运行设置保留当前会话的记忆与权限。玻璃包含透光、边缘高光、随指针反射，面板/弹窗提供过渡；动效可关闭并尊重系统减少动态偏好。用户通过工具箱明确提交的本地操作按表单执行；Agent 发起的副作用仍遵循 ask/auto/never 和原领域边界。

## 项目工具箱

工具箱按用途组织 13 个分组、68 项操作。右侧是内容工作区，已打开的源码、资料、计划和产物可保留标签、切换、展开及关闭；文件按原规则分页浏览，资料正文按版本与权限读取，重连保留标签但不缓存正文。点击右上角“操作”菜单打开当前功能表单，复杂参数在“高级参数”中核对。服务、子任务、配方与其他既有记录通过选择器引用；可重复步骤支持增删和排序。配方、浏览器动作、等待来源等只显示当前类型需要的字段，隐藏值不提交。步骤顺序、参数字节、修订和来源由领域模块再次校验。

| 面板 | 可操作能力 |
|---|---|
| 项目总览 | 仓库、职责、权限、依赖、原检查配置与真实联合验收 |
| 目标与计划 | 建立目标/步骤、原检查、依赖、版本进度和验收证据 |
| 代码阅读 | 符号追踪、索引、Schema/IDL、任务/diff 地图、来源展开、需求覆盖与讲解 |
| 项目资料 | 文件/笔记/HTTP/飞书来源、阅读、刷新、移除和原始响应 |
| 技能与配方 | 原生技能发现/阅读/实际调用、发现路径、配方编辑/参数/报告、成功任务提案显式推广 |
| 多仓库协作 | 隔离 Pi/Codex 子任务、状态/取消、三方合并预览与原检查；实验共同验收与选择 |
| 时光机 | 检查点、相对差异、预览、代码/上下文恢复、独立代码方案、未知操作核对 |
| 项目记忆 | 中文/符号检索、正文、用户保存/更正/忘记、来源经验草稿、整理/重建/恢复 |
| 运行观察 | 独立状态问答，实际阶段、来源进程、证据变化和仍未知的部分 |
| 环境与验证 | 服务/依赖/就绪、后台命令/取消/日志、等待/接续、浏览器定义/执行/报告 |
| 代码审查 | 新上下文只读冻结差异，来源报告与有效性 |
| 交接与复现 | 原始消息选择、背景交接、新任务、任务包导出/检查与新目录复现 |
| 产物 | 实际保存版本、来源状态、截图大图、文本预览和原字节下载 |

选择技能后在输入区显示标记，发送时调用 Pi 原生 `/skill`，不是在浏览器模拟执行技能。新背景会话会切换当前对话并保留源对话；共同背景不自动激活旧目标。代码恢复与上下文切换分别表达，用户新要求和累计消耗不退回。

操作有“运行中/完成/失败/取消/未知”和独立领域结果。命令结束不等于检查通过，子任务完成不等于父验收；结果为空也不能丢失记录。请求以原用户输入保存，结果是有来源的工作台事件，不伪装模型工具调用。保存结果与执行收尾后才释放会话，避免文件已改变但页面误报可继续。

## 视觉与恢复

桌面布局提供独立工具面板；窄窗口使用可以点击关闭的侧栏/项目抽屉，避免依赖 hover。液态玻璃用于侧栏、输入区和弹窗，主体文字保持清晰对比。支持低动态偏好和关闭玻璃，焦点、键盘发送、加载/空/失败状态均有明确入口。

重连只恢复视图，不批准或重放操作。待审批输入保留编辑值，取消不会被旧请求继续派发；设置变更也与任务执行串行。文本产物读取保存版本，最多预览 65,536 个字符、缓存四份正文；HTML 按文本显示，不执行脚本。

## 验证与限制

原全量回归与新版协议/浏览器测试验证实际模型请求路径、effort、配置保留、设置重开、计划/资料/记忆/服务/浏览器、失败和取消、技能展开、背景交接、任务包复现、隔离子任务及合并。真实 Gateway 页面分别使用 GPT-6.1-Sol 与 DeepSeek-V4.1-Flash 完成三仓只读链路、原联合检查和审批。

真实复验入口：`node scripts/gateway-workbench-interface.mjs OUTPUT_DIRECTORY`。当前报告位于 `<LOCAL_AUDIT_ROOT>/2026-10-25/enigma-next-validation/workbench-0.4-final-live/report.json`，包含模型、工具、审批、源码保护、原检查、截图和构建指纹。143 项完整回归、视觉审计与独立生产包安装分别记录，见 [本轮验收](acceptance-0.4.0.md)。

命令/浏览器/子任务仍是授权的宿主执行能力，不是 OS 沙箱。恢复不撤销远端数据库、网络或费用。托管管家、做梦与文档专精仍只有研究计划，不因出现工具箱而宣称已实现。GitHub Actions 保持关闭，Windows/Linux 当前版本未验证。
