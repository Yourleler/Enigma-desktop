## 玻璃与动效

玻璃层使用可透出的紫/青背景、饱和模糊、边缘高光、内侧阴影、渐变反射；桌面指针在玻璃面板上移动时更新高光位置。深色和浅色都采用相同层结构。主要动效是右侧面板展开/收起、弹窗入场、首次消息出现和按钮反馈；背景光晕慢速漂移。

设置提供独立“界面动效”开关，持久保存在浏览器，尊重系统 `prefers-reduced-motion`。关闭玻璃或浏览器不支持背景模糊时回退到实体表面。隐藏面板设为 inert，避免关闭后仍可聚焦。新增层次没有修改 Agent 运行、审批、原检查、恢复或模型协议。
