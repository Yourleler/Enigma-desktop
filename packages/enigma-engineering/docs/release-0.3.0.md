# 0.3.0 个人多仓库项目工作台

2026-10-25。基于 Pi 1.4.0 公共 SDK/插件，分支为 `codex/project-workbench`。本次已在用户明确的 Mac 场景验收；其他平台兼容性单列未验证。没有创建公开发布 tag 或自动合并 PR。

## 变化

- 多仓库阅读加入 Go/gopls、IDL/Schema、有界依赖展开、持久可重建索引、任务/diff 地图、职责与需求关联，以及来源版本核对。
- 项目资料提供 HTTP/飞书获取、刷新、原始来源和任务私有范围；知识草稿、整理与中文召回关联实际父任务证据。
- 多仓库服务、后台命令、浏览器流程、持久等待、事件接续和版本产物共用领域层。
- 原生技能发现、操作者推广配方、隔离 Pi/Codex 子任务、三方合并、同标准方案实验和任务包新工作区复现已经接入。
- 本地 Web 工作台使用公开 AgentSessionRuntime，支持真实流式会话、审批、取消、Fork/恢复、仓库、资料、地图、差异、服务和产物。文档/源码/报告提供保存版文本预览，HTML 不执行脚本，下载保留原字节。
- 修复立即取消后仍可能派发、页面漏掉最终空闲刷新、延迟面板响应覆盖新页面、验收脚本误选旧会话，以及初始化期间取消未传播到仓库探针的问题。
- Windows 状态发布的原子替换冲突加入有界重试；持久发布失败保留 unknown，不把旧运行记录当成功。

## 使用与证据

安装、Gateway 与工作台启动见 [README](../README.md)。架构见 [领域与宿主](architecture.md)，完整范围与历史失败记录见 [实施计划](workbench-plan.md)，逐条证据见 [候选版验收](acceptance-0.3.0.md)。

Mac 类型检查和 136 项原回归通过；最新真实三仓库完整流程的原五项检查、保护文件、回溯消耗、正常投递与 worker 退出通过。真实 Pi→Codex→Pi 和工作台审批/重连分别验证，独立生产包实际安装通过。受控机制与真实模型证据分别记录。[综合流程](full-workflow-acceptance.md)、[交互验收](interactive-workbench.md)

原云端三平台矩阵保留，但所有现有仓库的 Actions 已按用户要求关闭。本次不宣称当前 Windows/Linux 通过。本机与真实流程复验命令见 [验收入口](local-validation.md)，未来方向见 [创新与文档专精](future-innovation-and-document-specialization.md)。

托管管家、自动回溯、自修复与文档专精是未来提案，本版不启用这些行为。命令与浏览器仍是宿主执行，文件恢复不撤销外部副作用，不宣称全市场最优、全语言覆盖或跨崩溃 exactly-once。
