# 完整交互工作台升级与验收

2026-10-25。当前新 Goal 要求：以 Codex 的会话/输入区组织方式呈现完整个人工作台，右下角真实模型与思考级别选择，新加的相关能力可在界面操作，采用清晰、精致、可读的液态玻璃风格，反复浏览器验证。复用 Pi 公开 SDK/插件和现有领域模块，Mac 为实际交付平台，GitHub Actions 继续关闭。

## 功能契约

| 范围 | 完整操作 |
|---|---|
| 会话与输入 | 新建/搜索/重命名/切换/分支/续接；真实流式对话、工具结果、审批输入、取消；输入区右下角模型/思考选择，当前会话持久化，运行中锁定切换 |
| 模型 | 已配置模型与现有 Gateway 实际目录；搜索/分组/能力信息/刷新；既有认证保留，目录失败保留旧选择；测试实际不同模型调用 |
| 项目与计划 | 仓库/角色/权限/依赖、检查配置、真实联合检查；目标与步骤创建/进度/来源证据；概览显示有效、失败与未知 |
| 代码与资料 | 按问题源码/Schema/索引阅读，地图/需求覆盖与原位置；文件/笔记/HTTP/飞书资料关联、刷新、删除及来源；失效状态可见 |
| 技能与配方 | 原生技能发现、正文/版本/手动调用、配置发现路径；已推广配方参数运行/报告/编辑，成功计划提案显式推广 |
| 协作 | 隔离 Pi/Codex 子任务创建/状态/取消、真实合并预览/受控合并、同标准实验创建/比较/选择；不把子结果当父验收 |
| 恢复与交接 | 检查点/差异/预览/代码和上下文恢复/独立代码方案；来源条目选择、新背景会话、交接包/任务包导出与检查/恢复；保护新要求与用户文件 |
| 记忆/审查/观察 | 可选插件启停；搜索/保存/纠正/忘记/整理/知识草稿；用户触发独立审查/报告；独立问答、实际进展与等待信号 |
| 环境与交付 | 服务定义/依赖/启动/停止/重启/日志，后台命令/等待/取消/回执；浏览器场景/执行/截图/trace；产物创建/来源版本/文本预览/下载 |
| 视觉与可用性 | 侧边会话、宽松对话、底部输入与设置；项目工具清晰分组，响应式可点击抽屉；亮/暗、液态玻璃与低动态回退；键盘/焦点/加载/空/失败/成功状态 |

## 验收

逐项核对实际后端，表单操作产生真实文件、进程、会话或持久记录。模型列表/切换不能是占位，未配置后端与未知运行明确呈现。浏览器覆盖创建、切换、审批、取消、恢复、面板操作、原检查、重连和窄/宽布局；真实 Gateway 至少两种模型以及真实多仓库工具流程。截图逐轮核看，文字对比、布局溢出和焦点行为实际检查；最终独立安装与原完整回归通过。

当前旧工作台仅少量面板、没有当前会话模型选择，多数领域能力缺界面。此升级不将未来自动托管、做梦或文档专精提案变成已实现功能，也不改 Pi 内核或复制 DSH/Codex 私有实现。
