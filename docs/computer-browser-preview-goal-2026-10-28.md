## 0.452.70：弹窗、包内浏览器与多格式反馈

- alert/confirm 由真实浏览器事件观察，待处理弹窗不再占住 Agent 的操作队列；应答需要当前 dialogId 和显式接受/取消。无响应观察有界超时，取消释放等待。
- Electron 不实现标准 window.prompt；新增独立浏览器 preload，只提供网页输入弹窗这一能力，不暴露宿主 API。主窗口和独立浏览器工具栏都有输入/确认/取消界面。弹窗在页面销毁时释放；未登记为浏览器的页面无法调用此接口。自定义 prompt 桥目前随顶层浏览器 preload 加载，跨源子页面的 prompt 仍需单独兼容验证，不能声称全覆盖。
- 21 步真实弹窗测试通过：alert、confirm 接受/拒绝、prompt 中文/取消、旧弹窗 ID 拒绝。真实现用模型 9 次请求、8 次操作完成三种弹窗并核对回执。
- 子页面上传通过已授权路径解析；上传与拖拽在同源、跨源和嵌套三个页面全部实测。拖拽取消不留下按住的鼠标或拦截状态。

## 0.452.69：子页面、拖拽与文档预览

本版本为后续源码，尚未替换正式应用，也尚未完整打包。宿主/服务协议提高到 3，防止把依赖新浏览器命令及办公预览接口的内容激活到旧宿主。

- 浏览器支持列出子页面，在同源、跨源和嵌套 iframe 的独立环境中观察、输入、选择、点击、快捷键、滚动及等待。沿用快照身份；检查祖先 iframe 的遮挡，移除后的页面明确报错。旋转 iframe 明确拒绝坐标映射，要求视觉操作，不伪装成支持。
- 真实页面验证覆盖三层框架、中文输入、绿色选择、可信点击、系统对应全选快捷键和移除后旧引用拒绝。真实模型独立完成三个表单：15 次请求、14 次操作，三个回执逐一核对。
- 新增拖拽，使用页面生成的 DataTransfer 数据，检查两个目标的可见性与遮挡；取消时释放鼠标和拖拽拦截。22 步实际浏览器组合通过；真实模型拖拽/恢复任务 14 次请求、13 次操作通过。
- 工具提示收敛为小型参数约定，仍保留明确的 tabId、snapshotId、ref 和 frameId 规则。浏览器回归批次 117 项通过，另补取消拖拽和禁止编辑遮挡输入框的回归。
- HTML 的相对图片/脚本此前被 CORP same-origin 拒绝，因为预览 iframe 是不透明隔离来源。现只允许携带预览令牌的资源读取；不开放宿主能力。实测图片加载、脚本按钮、父页面拒绝访问，以及应用刷新后恢复通过。
- 欢迎页不再强制关闭已恢复的预览；挂载工作区也恢复远端文件引用。稳定引用不因后台刷新反复重建 HTML iframe。
- Word/Excel 转换统一交给已携带解析依赖的后端，避免桌面壳动态 require 缺失模块。支持多个工作表、明确的截断说明、20 MB 源文件/80 MB 展开结构检查；旧版 XLS 明确提示另存为 XLSX。转换后的 HTML 继续经过清理，不把文档里的脚本或事件属性放入宿主。
- 实测发现办公预览后台刷新曾用 ZIP 原始字节覆盖转换后的 HTML，现统一刷新路径。Word 正文、两个工作表展开、展开状态稳定和重载恢复通过；对应资源标识会持久化，临时访问凭证不会持久化。
- 三套类型检查、renderer 构建和本轮最后 46 项相关检查通过。导出清单补齐此前新功能漏记的模块，并把工作台资源解析放到公开服务层，避免新增对移动端产品路由的依赖；原有一条已登记边界债务保持不变。

已确认的差距：

- 电脑模型工具明确隐藏坐标点击、双击、拖拽；需要核对驱动真实能力及安全定位后补齐，不只放开 schema。

- 两类能力当前主要由宿主内置工具管理，需要接入明确的插件启停、能力说明、生命周期和既有会话权限，保留可靠的宿主底层。
