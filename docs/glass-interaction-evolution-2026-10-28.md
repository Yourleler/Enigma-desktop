# 玻璃材质覆盖与交互迭代

版本：0.452.59。用户目标：补齐适合使用液态玻璃的界面，并让已有材质更灵动；持续查阅 Apple 与 GitHub 公开资料。保留已确认的白天紫色光带、夜间青紫极光、无边框输入控件和固定主导航位置。

## 参考依据

- Apple 将液态玻璃作为导航与控件材料，交互具有缩放、回弹和光泽变化；相邻材料需要协调采样，避免玻璃互相采样产生视觉干扰。[SwiftUI 新设计](https://developer.apple.com/videos/play/wwdc2025/323/)、[Meet with Apple](https://developer.apple.com/videos/play/meet-with-apple/201/)。
- Apple 的自定义视图文档强调共享容器、连续身份以及形态过渡。本项目是 Web/Electron 实现，保留一个选中层并改变其位置与尺寸，不宣称调用了 SwiftUI 原生 API。[自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。
- 公开的 rdev 实现把折射、雾化、色散、弹性和鼠标响应独立配置，并说明浏览器支持边界；shader 模式有稳定性取舍。采用其“分别调节光学与交互”的思路，没有增加该库或复制其源码。[rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react)。
- shuding 的公开实验演示 SVG 位移滤镜路线。当前项目继续使用自己的有界边缘位移图和最多 40 张纹理缓存，不按每次鼠标移动重建纹理。[shuding/liquid-glass](https://github.com/shuding/liquid-glass)。

资料核对采用官方文档、公开仓库 README 和 GitHub 仓库元信息；没有将二手效果描述当作本项目的性能测量。没有导入未知脚本到用户浏览器。

## 覆盖与实现

| 界面类别 | 本次处理 | 可核对行为 |
| --- | --- | --- |
| 通用确认、通知与 Overlay 弹层 | 短弹窗接入折射材质；大弹窗使用稳定玻璃框 | 正文滚动时背景不移位，原焦点和确认逻辑保留 |
| 设置窗口 | 半透明外框、稳定内容底色、导航纵向选中层 | 左侧选择连续移动，不跳位，不使正文变形 |
| 工程区域 | 项目内容、模型分工、管家与操作弹窗统一材质；主任务导航有移动选中层 | 与左右导航配色统一，表单仍可读 |
| 活动、自动化、技能与社交面板 | 共用浮动面板材质 | 继承光带、浅/深色与减少透明度设置 |
| 同级切换 | 补齐活动分类、助手列表、引用类别、旧供应商用量页、仓库选择 | 同一个镜片随方向和距离伸展，经过高光后稳定 |
| 按钮、模型选择与开关 | 平滑指针光泽、按压与释放 | 无边框默认样式保留；仅交互时显示高光 |
| 菜单与提示 | 补齐权限菜单、提示卡、后台预览；更多功能和文件引用采用独立滚动层 | 不再让材质伪元素随列表滚出外框 |

指针跟随只有活动目标更新，位置平滑收敛后停止 requestAnimationFrame。失焦、离开、页面隐藏、关闭动效或玻璃时，立即清掉光泽和按压状态。禁用控件不响应按压，文本和输入框不会跟随指针位移。

选中层按位移方向轻微伸展，420ms 内回弹，并有一次扫光；文字不变形。大型导航和文本内容不增加逐像素纹理。JS 驱动的 FadeIn/Collapse/SlideIn/AnimatedList 也读取同一动效设置，避免只停 CSS、后台仍在播放动画。

## 验证

- 391 个界面测试文件、2,723 项回归通过；随后公共 Overlay/工程导航的 37 项定向复测通过。三套类型检查通过。
- 指针专项覆盖合并同帧更新、平滑收敛后停止、动态偏好切换立即清理、禁用按钮与文本容器不按压、卸载取消监听。
- 浏览器确认设置导航存在中间位移状态、主任务导航连续移动；模型分工弹窗实际背景 alpha 为 0.84、blur 14px、横向溢出为 0。深浅色已目视检查。
- 关闭动效后，活动光泽/按压数量为 0，主题选中层 transition 为 0s。
- 当前设备一次 180 帧场景采样：P95 17.7ms、平均 16.67ms。仅代表该场景，不是所有设备的帧率承诺。

原生 0.452.58 已验证设置导航、主题切换、玻璃/动效开关和技能助手切换。发现助手选择框圆角缺失，0.452.59 已补上 14px 圆角及上下留白，5 项助手切换与活动回归通过。最终包已签名安装，原生确认加载 0.452.59 并实看圆角镜片；服务健康检查为 200。

测试后恢复浅色、玻璃与动效开启、45% 清晰度，技能面板选择恢复全部技能并关闭。用户模型配置哈希不变，用量保留上限仍为 5,000，应用留在原对话。原生深浅设置、技能面板与浏览器模型分工截图已保存在本地验收目录。

本轮目标完成：已覆盖表内控件类别，修正交互及实际验收中发现的遗漏。未声称每个页面组合都做了逐像素认证，也不把 Web 材质称为 Apple 原生渲染。无发布、无合并，GitHub Actions 保持关闭。
