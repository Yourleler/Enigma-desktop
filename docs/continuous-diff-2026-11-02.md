# 多文件连续 Diff 与阅读接续

## 使用行为

全量Diff默认使用连续阅读。同一固定版本的全部筛选文件按顺序放在一个滚动区域，文件标题、来源仓库、变更状态及已读操作靠近对应内容。目录点击跳到文件；滚动和键盘翻页同步左侧选中位置。文件可单独折叠，仍可切换原有单文件阅读。

文件标题、阅读操作与已打开的查找栏保持在可见顶部，采用已有材质变量。深浅主题的语法颜色与源码预览共用；搜索高亮优先使用可读文字颜色，不被嵌套语法着色覆盖。

内容来自原冻结版本，已有新增、删除、重命名与归属说明保持不变。二进制或超出源码读取预算的文件保留明确说明，不展示伪造差异。查找针对当前文件，文件目录筛选针对名称与路径，不冒称跨所有文件的正文查找。

## 性能与交互修正

- 仅为视口附近的文件挂载CodeMirror，远处保留测量高度；每个编辑器仍使用自身的行虚拟化。缓存按连接、对话和版本分开，限制保存的版本数量、编辑器数量及文本总量。
- 目录远距离跳转期间，附近文件排版变化会重新校正目标；用户主动滚动或按键时立即解除校正，避免争抢控制。
- 只在用户改变当前文件的单双栏、换行或全文状态时恢复阅读位置。后台自适应排版不能移动整个文档。
- 可见区域由共同滚动容器计算，避免异步可见性回调在文件高度大幅变化时卸载正在阅读的文件。严格模式和重新挂载会清理并恢复滚动调度。
- 修复粘贴查询后第一次回车未命中的问题；输入事件即更新查询。查询、选择、全文状态及面板往返位置保留。

新建本地Git测试目录，实际读取50条文件变更，包括45个修改文件、删除、新增和二进制文件。未在用户项目制造改动，也没有发送模型请求。

- 第25个源码文件为1200行，第1100行发生变化。实际查找、全文展开、折叠、单双栏及智能阅读/全量Diff往返后，查询仍为同一内容，命中可见。
- 最终全文模式的文档高度约33,662px，视口为188–711px，命中位于约442px。50个文件仍在文档中，当前仅挂载1个编辑器、27行代码DOM。
- 目录跳到第45个修改文件，文件顶部与滚动区顶部相差不到1px。PageDown跨文件后目录选中同步变化。
- 二进制显示读取边界；无匹配筛选显示说明，清空后恢复。单文件与连续模式间查询保留。
- 深浅主题检查通过。深色使用统一语法配色；顶部查找栏实际位于约256px，高亮文字为深色、背景为橙色，未被代码配色覆盖。
