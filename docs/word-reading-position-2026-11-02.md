# Word阅读位置与搜索接续

继续文件预览验收时，在已有两页Word样本复现了两个问题：搜索命中第二页后从适应宽度切到100%，目标由视窗内约217px移到约1015px、离开442px高的阅读区；文本模式切回版式会清空搜索词。

## 修复

- 缩放前记录正在看的页面位置，缩放后恢复页面内同一点。当前搜索命中可见时，保持其位置；用户已滚到别处时，不强拉回旧搜索结果。
- 面板宽度变化的重排合并到动画帧，避免一次拖动重复计算。
- 同一文档的文本/版式切换保留查询；切换文档才清除，避免查询串到其他文件。
- 仍使用隔离的文档iframe，不修改Word原文件、纸张版式、授权或外部资源加载规则。

## 证据

旧版适应宽度搜索命中可见，100%后不可见。修复后适应宽度、100%、150%、返回适应宽度、展开和还原工作面板，命中均在可见区；文本模式显示1/1，切回版式后查询仍在，100%下保持高亮可见。
