# 对话变更与审查工作台

版本：0.452.169。对应此前的[能力核查与验收要求](review-and-change-workflow-audit-2026-10-31.md)。本文记录实现与本轮验证，不把模型意见当作实际执行证明。

## 使用方式

在右侧“变更”标签中选择本轮、整个对话、指定轮次，或本地仓库的未提交、暂存及分支/提交范围，再点击“查看变更”。对话产物不要求 Git 或 GitHub。代码、Markdown、配置及普通文本共用同一个冻结版本。

“智能阅读”按行为和源码片段展开；“文件差异”支持双栏/单栏、完整文件、搜索高亮、换行及上下处变化；“审查意见”提供独立模型核对；“影响关系”显示可缩放、筛选和跳转的源码关系。右侧加号可以添加“协作助手”，查看子任务并定位父对话中的发起消息。

审查发现按优先级、事实、影响、建议及来源行组织。可填写原因忽略、重新打开，或逐条交给助手修复。修复进入正常输入队列与权限流程，不能直接改写项目。复查只在新版本完整、来源有效、独立审查返回可验证的源码锚点时确认旧风险已解决；用户的忽略原因不会被后台复查覆盖。

## 数据与运行约束

- 从本版本的新输入起记录文件前后版本。旧对话缺失的历史不会自动补造；旧工程审查报告保留在历史入口。
- 每次扫描最多 4,000 个文件、约 12 MB、4 秒；单个文本上限 512 KB；内容地址存储上限 256 MB。超限、二进制、符号链接、读取错误及中断都有范围说明。容量满后不自动删除旧证据。
- 资料只存在本机应用数据中；原目录不会被自动初始化为 Git。分析使用另外生成的只读冻结目录。文件目录权限和模型限制每次请求重新核对。
- 可查看、解释和审查旧冻结版本；来源已变化时不能直接提交旧意见修复。新文件、未改动上下文的变化和 Git 工作区变化也参与过期判断。
- 每个对话同时最多一项模型分析；独立审查最多 12 次请求，模型阶段限时约 150 秒。取消/错误不会变成完成结论。原任务模型预算继续生效。
- 审查要求和历史风险有组合文本预算；超出可读范围时不声称覆盖完整项目。关系图最多展示 120 个源码节点，属于导航视图，不是运行时依赖证明。
- 对话文本质量检查是另一类对象，不把文件审查称为完整的对话内容评审。本轮没有新建远程 PR/MR 集成。

## 本轮验证

- 43 项工作台、记录、接口、父子定位、差异与标题栏专项回归通过。

- 完整 Mac 候选包签名、种子校验与启动通过；原生实操打开独立审查历史和带锚点的原风险复查。正式应用、服务与 Web 资源均已安装为 0.452.169。13 个保护文件中，12 个字节一致；偏好文件仅更新已有预览标签的来源目录和界面保存时间。模型凭证、对话正文、图片及富文本草稿均未变化，完整备份保留在仓库外。

## 公共技术来源与许可

差异编辑器直接依赖 [`@codemirror/merge` 6.12.3](https://github.com/codemirror/merge)，使用官方 [MergeView / unifiedMergeView API](https://codemirror.net/docs/ref/#merge)。这是实际开源依赖复用，许可证为 MIT；保留的版权与许可文件位于 `desktop/src/assets/licenses/codemirror-merge/LICENSE`，随应用资源打包。

界面遵循 Apple 的[布局](https://developer.apple.com/design/human-interface-guidelines/layout)与[侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars)原则：明确的列边界、内容优先、按宽度收纳辅助控件。窗口、业务流和记录逻辑由本项目实现，不包含非公开参考实现代码。
