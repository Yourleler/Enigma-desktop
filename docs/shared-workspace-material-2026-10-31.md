# 三栏统一材质与设置光斑

界面版本：0.452.170。宿主与服务保持 0.452.169，本轮仅更新共享界面资源。

## 用户目标与实现

- 顶栏与最左侧工具栏贯通，使用同一套较通透的底色和模糊参数。
- 中间对话、左侧对话列表、右侧工作面板共享一个偏暗的内容底层。以前中间使用卡片底色、两侧使用侧栏底色，并各自叠加玻璃伪元素；现在只在包裹三栏的圆角框绘制一次底色和模糊，子列透明，不再因叠层不同产生色差。
- 三栏保留原有分隔和独立滚动。内容层的模糊始终高于外侧工具条：滑块 0/50/100 对应内容 2/8/32px，外层 0.5/2.25/11px。输入框和小控件的最大液态玻璃效果未改动。
- 设置光斑半径由 180×120px 改为 110×74px，宽高分别缩小约 39% 和 38%。采用同色相的多段柔和衰减，移除设置面板额外的大范围线性反光；一层极轻的单色程序纹理减少低透明渐变的量化断层。纹理只画在背景内，不覆盖文字或拦截点击。
- 关闭玻璃及系统减少透明度时仍采用一致的不透明底色，不额外保留光斑纹理。

## 验证

16 项既有材质同步、滑块端点、指针光斑和设置开关回归通过；共享 Web 资源构建通过。Web 实测深浅主题的三栏背景、滑块两端、玻璃关闭、设置页切换、空白处移动光斑与中文内容可读性；计算样式确认三列均透明并共用框体背景。没有修改模型配置或发送新的模型任务。
