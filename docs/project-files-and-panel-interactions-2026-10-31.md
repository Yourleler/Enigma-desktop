# 项目、文件与面板交互整理

版本：0.452.151。日期：2026-10-31。

## 使用关系

- 普通对话可独立存在，不需要先创建项目。全局“新对话”默认不归属项目；历史上按工作目录自动归组的对话保持兼容。
- 项目负责归拢对话、共享说明与笔记。目录可选，可同时登记默认目录与其他协作目录。目录清单不自动扩大文件读写权限，也不会搬动文件。
- 默认目录用于新对话和首次打开工程工具；已有工程任务保留自身绑定，避免修改项目设置后悄悄切换正在处理的代码。
- 无目录项目可以使用计划、记忆等工具。首次打开时在应用数据目录中建立该项目的任务记录；同一项目的对话共用项目记录，独立对话分别保存。
- Git 仓库在“仓库”面板中登记。每个仓库有独立位置、职责、依赖与读写权限；已在项目设置中登记的目录提供加入入口，默认选择只读，提交时检查实际 Git 仓库。
- 项目内新对话从左侧项目的加号开始。项目设置、共享背景和目录管理从项目行悬停/键盘聚焦后的设置按钮进入。当前对话顶部不再常驻项目设置。

## 交互改动

- 文件树与文件预览之间增加分界线，可拖动、方向键微调，双击还原。宽度按对话保存；窄面板继续在文件列表与预览之间切换。
- 面板标签使用按位置计算的排序和已有 Motion 依赖的布局动画；拖动时显示浮动标签与目标空位，其他标签实时让位，松手后保存顺序。隐藏标签位置与内容状态保留；支持减少动态效果。玻璃高光按布局位置定位，不跟随排序期间的临时变换而留在错误标签。
- 文件树显示实际 Git 新增、修改、改名与冲突状态。已删除文件有独立折叠列表，可以打开变更面板查看；状态包含仓库全部未提交改动，不表示全部由本次对话产生。
- 对话文件显示上传、生成等已有记录；不将本机打开预览冒充模型读取。
- 项目内对话缩进，并使用浅色引导线与独立对话区分。设置关闭按钮固定为 28×28；修复项目菜单被侧边栏覆盖、点击穿透，以及文件状态挤到下一行。
- 文件树与预览去掉重复卡片边框，沿用统一的玻璃背景。

## 公开技术来源
