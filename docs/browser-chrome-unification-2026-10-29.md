# 浏览器侧栏与独立窗口统一

状态：0.452.101 桌面候选已构建、本地签名并通过启动验证。候选内服务版本为 0.452.100，预加载接口协议为 6，服务协议保持 6。用户正式应用仍为 0.452.91 界面、0.452.81 服务；Mac 锁屏阻止本轮原生点击，不将候选等同已安装。

## 改动

- 侧栏与独立窗口共用 `BrowserChrome`，地址栏、网页标签、后退/前进、刷新/停止加载、下载、缩放、查找与状态具有相同布局和行为。去掉独立窗口原来的第二套控件和样式。
- 独立窗口补地址栏，支持原标签导航；“放回侧栏”返回同一网页实例，不主动重载表单。独立下载也能发回主窗口预览。
- 页面查找直接用 Chromium `findInPage`，显示实际匹配数、当前序号，支持上下匹配、大小写、Enter/Shift+Enter、Escape。新查询、导航、关闭和切换标签时旧结果不会串入；输入防抖不会覆盖 Enter 已发起的跳转。
- 页面缩放直接用 Chromium 的缩放 API，范围 25%–300%，可一键恢复。支持网页聚焦时 Cmd/Ctrl+F/L/T/W 及加减/0；快捷键发给所属浏览器，不误操作其他会话。
- 所有操作通过当前宿主/当前会话和标签校验。独立窗口消息只能由其顶层工具栏发出；切换会话、网页移入侧栏后旧命令被拒绝。
- 原生网页按控件实际高度定位。查找/下载区域展开时会重新计算，短窗口可滚动控件区；空间不足时隐藏网页，避免覆盖按钮。
- 状态从同一入口推送到侧栏、独立窗口与运行时，后台标签关闭和下载状态变化不再依赖两套不一致的刷新路径。

## 复用依据

内核继续使用 Electron Chromium。调用的是已安装 Electron 42.3.0 的公开 API，本地类型声明与真实引擎试验均核对了参数语义；没有用自写 DOM 搜索模拟完整网页搜索。

- [Electron webContents 文档](https://github.com/electron/electron/blob/v42.3.0/docs/api/web-contents.md)：`findInPage`、`found-in-page`、`stopFindInPage` 和缩放。
- [Min 页内查找实现](https://github.com/minbrowser/min/blob/master/js/findinpage.js)：参考其搜索与活动标签关联、导航/隐藏后结束旧查找的组织方式。本轮没有复制 Min 源文件；上游整体依赖自己的工作区框架，不作为 React 组件嵌入。
- 文件预览继续复用已经引入的 Mozilla 完整 PDF viewer 和 docx-preview，后续表格、图片、媒体按 [开源复用计划](open-source-preview-adoption-2026-10-29.md)推进。
