# 连通外框与圆角边缘

已交付界面：0.452.174；宿主与服务为 0.452.169。本轮沿用并包含[输入框与图片固定预览](composer-image-focus-2026-10-31.md)的全部改动。

## 原因与处理

顶栏、左侧工具条分别绘制色底和背景模糊；圆角内容框之外的右侧/下侧空隙则没有相同的材质层。因此即使前两者使用相同参数，交界处仍会出现渲染边界和色差。

现在在动态背景上方建立一个覆盖整个窗口的连续材质层，统一承载顶栏、左侧工具条、外围空隙和圆角露出的背景。各个工具条本身透明，不再各自模糊一次。三栏内容继续使用同一块更浓、稍暗的内容材质；两层共同跟随原有清晰度滑块。

嵌入式文件预览外壳改为透明，HTML 的圆角只由一个容器裁切，移除多余边框/卡片底色，避免圆角旁残留不同颜色的方块。网页内部的实际颜色不做覆盖，白色网页仍按白色显示。
