# 工作对话返回管家与验收对账

版本：0.452.216。

原生检查发现：管家任务卡可以打开工作对话，但工作对话没有清楚的返回入口，用户必须在侧栏中寻找原管家。现在受管工作对话的顶栏显示一个紧凑的“管家”返回按钮，使用原先保存的受管任务归属，回到创建该任务的管家。不会新建会话、停止任务或扩大权限。

接口只返回导航所需的managerSessionPath，不向界面发送受管模型授权清单。普通对话不显示；正在切换对话、旧快照或错误地指向自己的记录不显示返回按钮。

## 实际验证

- 原生管家显示1个真实已结束的只读工作对话、累计2次模型请求和“验收仍需核对”。从任务卡打开工作对话，正文是先前实际读取的接口首行。
- 216完整包中显示返回按钮，点击后回到对应的“任务编排管家”及原任务概况。原会话与工作内容保留。
- 14项归属、导航、迟到响应和会话切换回归通过；renderer、宿主和测试类型检查通过。第一次新增测试在组件挂载前写入快照，被组件已有初始化正确清除，改为模拟真实异步快照到达后测试通过；没有放宽业务行为。
- 原生工具对同名正式/测试实例和辅助功能树存在偶发定位问题。本轮在测试实例上用Electron辅助功能开关重启，并确认正式应用空闲后暂时退出正式实例，减少干扰；未修改产品默认设置。正式应用在安装后恢复。
- 测试视频在原生播放器中播放且时间推进，但全屏及关闭组合未取得可靠终态，没有据此登记为全部通过。

## 完整目标

收尾对账已根据212–215的实际证据更新，移除已经完成的日期、控制取消、文件恢复和阅读入口等旧待验描述。纯悬停、系统快捷键、部分协作/媒体/设置组合和最终完整审计继续保留；外部账号闭环仍需实际账号与发送范围。没有用本轮导航修复缩小完整目标。

216完整包已签名安装，服务返回216、主窗口记录app-ready，正式应用已恢复。69项保护文件无缺失，模型、会话及图片草稿保留；变化仅为每日整理、版本标记和工作台界面状态。最终包7,821个文本文件完成既定私有模式扫描无命中，测试实例已停止。
