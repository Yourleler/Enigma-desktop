# 新对话布局、多仓库引用与系统终端（267）

## 本轮行为

- 新对话的欢迎内容与输入框在可用聊天区域中居中。发送后回到正常对话布局；小高度窗口允许滚动，不裁掉输入工具。
- 目录选择移到输入框下方，已有主目录与其他仓库用紧凑标签展示。标题旁增加仓库入口，可查看多个目录、Git当前分支及主目录身份。
- `@` 分类包括仓库、分支、文件、GitHub、对话和助手。文件／文件夹、历史对话及助手沿用已有引用能力；本地仓库和分支作为资源标签插入输入位置。
- GitHub读取本机GitHub CLI已登录账号有权访问的仓库，支持进入仓库、选择分支及分页。分支标签保留仓库URL、分支名和选择时的提交。未登录或未安装CLI时显示登录／安装说明，应用不接收或保存GitHub密码。
- 资源标签随已有草稿文档保存；发送给模型的是完整引用，聊天显示简短标签。引用是资源定位信息，不代表已下载整个仓库，也不会自动克隆或切换工作分支。
- 工具菜单增加“打开终端”，多仓库时列出目录供选择。桌面应用调用系统终端并设置工作目录，不自动执行仓库命令；Web会明确提示系统终端需要桌面应用。Web可在仓库菜单输入服务器目录，桌面使用系统目录选择器。

仓库选择、文件读取及终端是不同操作。标题菜单展示当前授权目录；添加目录沿用现有会话目录授权。GitHub账号资源仅通过本机用户入口读取，不开放给远端配对客户端。
