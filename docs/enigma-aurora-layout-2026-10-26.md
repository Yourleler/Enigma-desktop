## 核对后的事实

上一个 Agent 增加了 token 计量、男版头像、工程 CSS 和新的全局玻璃文件；没有提交新 commit，该审计基线经历史清理后对应 `83a7d963`。阅读其交付记录后又核对了源码和当前浏览器，没有把文档中的“已完成”直接当作验收结果。

发现并处理：

- `engineering.css` 与 `enigma-glass.css` 同时控制背景和玻璃，深色实际偏蓝灰，浅色混有蓝青暖色。现在统一为一套 Enigma 语义调色，沿用宿主主题选择而不增加另一套主题注册表。
- 三个玻璃变量自我引用，无法产生颜色；当前页面的部分字号、10px间距引用也为空，按钮留白变成0。修复变量并在实际页面核对计算样式。
- `enigma-progress` 同时被当作4px进度轨和状态文本栏，文字被压缩裁切。分开轨道与状态栏，保留原检查、运行/停止、待切模信息。
- 菜单位于玻璃工具栏/裁切面板的后代；模态弹窗也可能嵌在带filter的侧栏，fixed位置受祖先限制。统一浮层渲染到body，按按钮位置约束在视窗内；支持点外关闭、Esc、键盘导航和焦点返回。
- 右侧关闭按钮与标签一起横向滚动，会在标签过多时消失。关闭按钮独立固定，只有标签列表滚动。
- 窄窗抽屉缺完整交互，布局逻辑还可能把覆盖抽屉计入聊天占宽。补遮罩、背景inert、焦点限制和Esc关闭；面板内容滚动，保留聊天和已开标签。
- CSS clamp宽度不能用parseInt计算真实占宽；布局管理器读取实际右栏宽度，窄窗覆盖模式不占聊天布局。
- 长路径、多层通用卡片和继承字号让列表冗长拥挤。路径单行省略并保留完整title，降低次要信息层级，卡片左对齐，表格/代码滚动局限于自身。
- token计量的特殊阶段点缺基础圆点样式，关闭动效/玻璃没有覆盖该组件；补齐这些状态，数据和传输逻辑保留。
