# 历史搜索展开命中内容与工具组键盘操作

界面0.452.225；宿主与服务仍为0.452.222。

## 原生验收发现的问题

历史搜索能区分用户输入与模型回复，也能按模型筛选和恢复无结果状态。但关键词落在折叠的工作说明中时，定位只滚到消息容器，说明仍折叠，用户看不到命中文字。另一个缺口是多工具摘要使用普通div，只能鼠标展开，键盘与辅助功能没有按钮语义。

## 修复

- 搜索定位只展开目标消息中实际匹配的工作说明或思考块，以及包住目标消息的执行过程。非目标说明不展开，用户手动收起后不会被无关更新反复打开；重新定位可以再展开。
- 展开后按实际命中文字的位置滚动，给顶部查找条留出空间。搜索定位的展开即时完成，避免读取动画中的错误高度；普通手动展开仍沿用动效。
- 多工具摘要改为有展开状态的原生按钮，完成后支持Tab、Enter和空格，运行中保留进度但不误触折叠。保持此前无灰底样式。
- 查找输入、上一个、下一个与关闭使用语言包中的可访问名称，补齐现有五种语言。

## 验证

51项搜索、定位、工作说明、执行过程和工具组检查通过，另5项思考块与文本范围检查通过，renderer和测试类型检查通过。覆盖嵌套折叠、只展开目标、重复定位、手动收起、跨会话隔离、长消息按词定位，以及既有分页与定位无进展保护。

真实Web在既有对话中搜索“美化”的模型回复，工作说明自动展开，命中文字显示橙色高亮，上一/下一匹配正常。隔离历史中的4工具组通过Enter展开、空格收起，未运行工具或改文件。

正式Mac更新后重复同一历史搜索流程：说明正文实际可见，橙色命中位于查找条下方，原生截图与辅助功能状态已保留。更新前还实测了用户/模型来源、无效模型空结果及恢复为实际模型。

通过现有签名资源更新交付；76项保护文件无缺失，模型、会话和草稿保留，既有每日整理与界面状态正常更新。临时Web与隔离服务已停止，仅运行正式应用。本轮补齐搜索原生证据，不代表全功能Goal已经完成。
