# 音视频预览：Video.js 完整控件

日期：2026-10-29。界面版本：0.452.120。延续浏览器与文件预览的开源复用目标。

## 已实现

使用 **@videojs/react 10.2.0** 的完整 VideoSkin / AudioSkin，替换应用自写的播放、定位、音量、倍速、全屏和画中画按钮。侧栏和 PhotoSwipe 混合画廊共用同一个播放器适配器；字幕、菜单、快捷键、手势、焦点与状态播报由上游提供。

本项目保留文件来源与版本身份、本地资源路由、播放位置/音量/倍速恢复。默认不自动播放；切换画廊、隐藏页面、关闭预览会停止播放；关闭卸载媒体并释放字幕 URL。播放位置限于当前应用窗口生命周期，最多 64 个文件版本，不宣称重启后的播放历史。

视频可加载本机 WebVTT 字幕（.vtt，最多 2 MB），支持显示/关闭和字幕选择。文件只在本地读取，不上传。没有自动搜索旁边的字幕文件，也不声称支持所有字幕格式、转码或 DRM。实际可解码格式取决于浏览器/系统。

应用只在上游外层提供状态、加载字幕与系统控件备用入口。切换系统控件会保留进度、音量和倍速，并保持暂停；播放被拒绝或宿主拒绝全屏/画中画时给出可读恢复提示。修复原预览面板过宽的按钮 CSS 选择器，使上游白色图标、图标网格和菜单样式正常生效。

## 实测范围

使用隔离配置、新建 20 秒原创视频、32 秒 WAV、WebVTT、原创图片及损坏文件。正式用户配置、模型、会话和草稿不参与测试。

- Web 实际播放/暂停、当前时间推进、定位、倍速与原生控件来回切换通过。
- 本机字幕选择后，画面实际显示中文字幕；设置出现字幕条目与开关。
- 420 像素窗口可打开倍速子菜单并选中 1.5×；播放器宽度与滚动宽度一致。
- 深浅主题检查通过；修复浅色主题视频图标过暗及受外部 padding 挤压的问题。
- 混合画廊的视频内方向键只定位，不翻图片；播放后切图片，媒体实际 paused；返回保持时间且不自动播放；放回侧栏保持进度。
- 损坏视频出现中文原因；重新加载仍给出错误，不无限等待。
- 41 项定向回归覆盖失败提示、StrictMode、隐藏/关闭、延迟 play 完成、播放状态恢复、本机字幕验证与释放、媒体来源与画廊生命周期。

**尚未确认的范围：** 内置测试浏览器的全屏/画中画点击未获得稳定的进入证据，不记为通过。完整 Mac 候选的全屏、画中画、触控板手势及正式应用安装仍须原生验证。对应失败回执通过受控回归，但不替代真实宿主验证。

## 复现方法

构建界面后，运行 `node scripts/verify-media-controls.mjs <外部证据目录>`。它创建隔离测试目录与媒体，启动工作台并输出地址；使用该测试配置的本机登录方式进入。按上述步骤实操，通过浏览器/原生界面确认结果，结束时 Ctrl+C 停止测试服务。

原脚本中依赖旧自写按钮结构的隐式点击驱动已移除；现在输出明确是“待人工 UI 验收”，不会把启动成功写成测试成功。视频生成器仅绘制原创测试画布，长片段按块编码，避免展开整个字节数组导致栈溢出。
