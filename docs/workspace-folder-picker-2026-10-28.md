# 系统文件夹选择与工作区确认

版本 0.452.56。

旧界面只提供必填路径输入框，空提交触发浏览器自带的“请填写此字段”气泡，没有接入桌面系统选择器。

- 本机桌面点击“选择工程工作区”直接调用现有 Electron 原生文件夹选择接口。选中后显示文件夹名称、完整路径、更换按钮和工程记忆开关，再连接。
- 首次系统选择取消时关闭本次流程；更换目录时取消则保留之前选择。弹窗关闭或切换对话后，过期选择结果不再生效。
- 手动路径输入保留为备用入口。网页/远程连接使用服务端路径输入，不把本机文件夹路径误传到远程服务。
- 移除 HTML 必填气泡；空路径禁用连接按钮，系统选择失败或连接错误显示在界面内。
- 采用文件夹确认卡、简短说明、开关和统一页脚，替代大块必填表单。

验证：13 项选择器、状态隔离及原有表单回归通过，另 2 项本机/远程接线验证通过；三套类型检查通过。测试包含 StrictMode 只打开一次系统窗口、取消、更换取消、失败回退、空路径和迟到结果处理。

已在隔离服务连接临时工作区并进入项目面板。桌面版已签名安装，原生窗口确认 0.452.56；实际点击工程入口后立即打开 macOS 系统文件夹窗口，选择带空格的临时目录后，确认卡显示正确名称和完整路径。取消确认及取消系统选择均返回原对话，没有留下空表单或改变原工程绑定。模型配置哈希不变。
