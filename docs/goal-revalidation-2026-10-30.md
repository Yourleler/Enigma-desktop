## 原目标逐项核对

“领域回归”包含真实临时文件、进程和 Git 操作，但模型输入可受控；“真实模型”仅指实际后端返回，不代表穷尽供应商组合。此前已完成的实测保留在旧验收记录，本轮没有重新执行所有历史场景。

| 原目标 | 当前实现和本轮证据 | 实际范围与限制 |
|---|---|---|
| 个人 coding agent / Pi 插件 | 普通会话、工程宿主、插件接入回归；真实后端三仓任务；原生请求循环 | Pi 1.4.0；Mac。未把 Windows/Linux 当成本轮完成条件 |
| 多仓协同 | workspace、依赖/隔离/恢复、跨语言领域回归；真实后端修改 library→sdk→app，原检查再执行成功 | 本轮真实模型案例是三个 JS 仓库；跨语言为领域回归和既有实测 |
| 智能阅读 | 固定变更集、任务路线、语义/Schema/Go 阅读、MR 来源与失效回归；host reading 入口 | 既有真实 PR 与暂存证据继续保留；本轮未新建或发布 PR |
| 时光机 | context-rewind、checkpoint、partial-restore、recovery 回归；host timeline 入口 | 既有真实模型主动纠偏证据有效；本轮没有重演所有未知外部副作用 |
| 原要求、计划和独立验收 | task-acceptance/planning/delivery 回归；真实任务计划 3/3 verified，重新执行原检查 | 不把修改测试使其变绿当完成；三个原 package.json 均保留 |
| 记忆与中文召回 | memory/index/lifecycle、项目知识与隔离回归；host memory 入口 | 带来源与适用条件；长期记忆质量需要持续实际使用评估 |
| 增量整理 | memory-dream、增量发布、取消恢复与预算回归 | 不宣称任意便宜模型能达到同样质量 |
| 旁路观察 | observer/边界/问答回归；host observer 入口；运行状态展示实测 | 无新事件明确说明未知进展，不将静默等同于卡死 |
