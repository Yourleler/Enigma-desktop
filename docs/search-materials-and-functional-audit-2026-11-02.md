# 搜索材质与功能补验

## 已确认问题

附件搜索使用半透明底与较大的内边距，目录搜索仍使用旧24px实色输入框。同一文件面板切换来源后，材质和高度一起变化。工程搜索、设置搜索和正文查找也有各自的固定底色，部分不会跟随清晰度调整。

此外，嵌入预览沿用旧`universal-card`底色，导致Word、表格等工具栏被实色底板隔开；三个新分析/筛选菜单没有接入共用菜单材质。

功能核查发现目录搜索失败时被转成空结果，切换到另一个目录后旧请求仍可能返回；Web开发入口的表格地址误用发行资源路径，可能加载工作台首页而非表格。

## 修改

- 用共用搜索控件/材质标记覆盖17个使用位置，包括目录、附件、变更、任务成果、时间线、源码关系、工程操作、配方、选择器筛选、文档、历史和设置搜索。
- 目录和附件搜索均为32px高、9px圆角、同一字体/内边距，颜色与模糊随已有清晰度滑块变化。没有改变原液态玻璃最大效果或滑块公式。
- 嵌入预览移除重复实色底板，沿用整个工作区材质；文档纸张、图片、PDF与表格画布保留文件内容本来的颜色。搜索结果、变更筛选、分析历史和版本选择使用共用菜单材质。
- 目录搜索显示真实错误及重试。切换目录/连接/对话时清理旧搜索，迟到结果不能写回新目录。原有文件引用搜索调用继续兼容。
- 表格在Web开发模式使用真实开发入口；发行构建继续使用版本化资源。

## 实际证据

- Web深浅主题下逐项比较目录/附件搜索的背景、blur、边框、圆角、字体、内边距和尺寸，结果相同。默认blur 1.5px；清晰度两端分别0.5px与20.5px，样式跟随设置。
- 真实目录搜索找到测试Word并打开；两页版式、页眉页脚、合并表格和图片正常，跨页标记命中1/1且可定位。
- 表格显示3张工作表、1张隐藏、21个单元格。数据页B5保存结果为15、复制内容为15；切换汇总页B1，跨表公式与保存结果一致。开发入口修复后取得上述结果，失败的中间页面不计为通过。
- PDF实际显示两页及正文，页码可操作；外层材质不再遮盖工作区。设置搜索能跳到真实的玻璃选项。
- 128项搜索/目录/设置/历史/变更相关检查通过；10项Word/表格回归及2项搜索错误/迟到结果复测通过，三套类型检查与界面构建通过。

## 尚未完成

Mac锁屏阻止本轮原生Office、纯悬停及电脑操作组合验收。Web和组件测试不替代原生证据。原始完整目标不变，不能把这些项目标成已完成。

既有电脑操作已有真实原生读写、点击、单次前台拖放、取消释放和鼠标隔离证据；浏览器已有真实表单、frame、弹窗、上传下载等证据。这些场景不证明任意应用/所有组合等效。外部账号能力、系统通知，以及阅读模块仍有的连续Diff等差距继续列在[完整对账](acceptance-closeout-audit-2026-11-01.md)中。未支持的能力必须明确显示限制，不能用入口存在或模拟结果充当功能完成证明。
