# 交互与功能可理解性检查

2026-10-26。用户要求检查交互问题，以及让人看不懂用途的功能，重点是时光机。最终桌面版本 **0.451.2**，沿用上一轮 Codex 风格设计。

## 发现与修复

1. **时光机三种用途混在一起。** 新界面区分“恢复代码”和“助手纠偏”，另开代码方案作为快照旁的直接入口。“该用哪一种？”解释具体场景、文件是否变化、如何向助手提出纠偏要求。助手纠偏记录保留原因、经验与下一步；压缩之前的位置为何不可用也可展开查看。
2. **代码检查点难以辨认。** 默认英文标签译为中文；每项显示本地时间、来源对话范围、涉及仓库。下拉框用时间和短标识消除重复名称，快照列表可筛选。原始用户命名保留。
3. **恢复表单的“当前基线”含糊。** 选择快照时自动带入目标及最近记录的核对基准，解释为什么当前文件必须匹配基准。恢复前仍由原有底层逻辑重新检查外部修改、Git 历史和权限。
4. **预览结果藏在原始数据里。** 现在直接显示目标、基准、差异文件和冲突原因，可展开逐文件 diff；结果自动定位到可见区域，支持关闭预览。没有差异、存在冲突或正在运行时，恢复按钮不可用。有差异且无冲突才进入最终确认，默认只恢复代码。
5. **失败或取消后仍可能显示运行中。** 原状态比较漏掉“同一 operation 从 running 变为 failed/cancelled/unknown”。现在这些终态都会更新结果区域，并显示明确状态。
6. **选项加载失败藏在弹窗背后。** 表单内显示加载和错误状态、提供重试；加载未完成或失败时禁止提交。无选项依赖的简单表单不再请求全量选项；不同会话/服务、旧请求的晚到响应不会污染当前表单。
7. **菜单截获文本编辑按键。** 输入框或选择框中的 Home/End/方向键交给控件自身处理，按钮列表仍支持方向键导航。
8. **背景交接、技能/配方和协作缺少使用入口说明。** 增加用途、常见选择、直接操作入口和可读摘要；完整技术记录折叠保留。运行状态与后台任务状态也改为中文表达。
