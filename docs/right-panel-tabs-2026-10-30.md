# 统一右侧工作面板

日期：2026-10-30。版本：0.452.143。

## 信息结构

右侧从“文件、任务卡片、代码变更、独立预览列”的堆叠布局，改为一个可以切换的工作面板。标题栏只保留一个面板开关。

| 标签 | 内容 |
|---|---|
| 文件 | 项目文件和对话附件；目录标题可打开系统目录，低频的自动整理说明和项目技能保留在目录工具中 |
| 变更 | 同一源码版本的智能阅读与完整差异，支持工作区/暂存区 |
| 浏览器 | 现有Chromium页面与网页标签，切换到其他内容后保留网页和输入 |
| 任务 | 计划进度、协作助手、运行信息和检查入口 |
| 文件名 | 每个已打开文档独立的可关闭标签，继续使用现有Markdown、代码、PDF、Office及媒体预览器 |
| 已打开的工具 | 从项目工具菜单打开的具体功能，和上述内容共用右侧空间 |

项目工具按“项目与执行、阅读与交付、恢复与知识”归组。可见名称缩短为项目、计划、协作、变更、资料、成果、文档、检查结果、记忆、技能、交接等；具体用途放在说明与悬停提示中。没有复制任何私有产品的源码或内容。

## 交互与数据

- 打开文件自动选中对应标签；文件预览不再增加第四列。
- 切换文件/任务/变更/浏览器不清空已打开文档，浏览器使用原生视图的可见性控制，不重新加载网页。
- 原有文档内容、Markdown编辑保存及阅读位置继续使用已有持久化机制。标签选择按连接与对话隔离记忆，不继承另一个对话的选择。
- 面板可以调整宽度、展开到较大阅读区、还原、收起；窄窗使用同一抽屉，保持正文可读。
- 顶部标签支持方向键、Home/End，过多时横向滚动；文件标签可单独关闭。
- Web继续支持文件、变更与任务；真正的内置Chromium浏览器需要桌面应用，Web入口明确解释当前能力。
