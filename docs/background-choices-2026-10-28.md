## 0.452.66 大理石条带修正

用户明确要浅白底上淡淡的不规则条带。此前连续等高线状波纹、深色轮廓与相邻亮边产生了明显浮雕感，现全部移除。改用独立的低对比淡紫色纹理带，宽窄、浓淡和出现区段分别变化，保留大量浅白留白。动态变化减缓；缩略图和无 WebGL 回退同步改成相同方向。玻璃效果与背景选择不变。

验证采用真实 WebGL 画面、不同时间的纹理检查及生产构建；仅调整纹理公式、资源与说明，不新增同构单元测试。桌面安装状态以 README 为准。

## 使用

- 设置 → 界面 → 背景：分别选择深色、浅色背景。
- 工作台外观菜单：直接选择当前模式的背景。
- 深色提供「拟真极光」「光环」；浅色提供「紫色光带」「紫色大理石」。预览卡片显示选中勾选，选中镜片延续玻璃移动效果。

两个模式分别保存选择，切换主题、跟随系统或重启不会相互覆盖。旧配置继续默认深色极光、浅色紫色光带。背景不会更改玻璃开关、清晰度、模型或工作区配置。

## 实现

背景偏好复用已有本地外观存储，设置与快捷菜单使用同一个选择器。光环恢复此前青紫环形光带。大理石使用自行编写的多层连续噪声生成浅紫石纹、细线和缓慢流动波纹；没有新增外部素材或依赖。

极光和大理石共用一个 WebGL 画布及现有绘制限额。选择光环或原有光带时暂停画布，采用原来的 CSS 效果。窗口隐藏时暂停绘制；关闭动效或系统要求减少动态效果时定格。无 WebGL 时使用静态纹理回退；玻璃与可读性回退保持独立。
