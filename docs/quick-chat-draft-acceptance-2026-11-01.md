# 快速聊天草稿、发送与图片历史验收

版本：0.452.211。范围为快速聊天已有能力的可靠性与界面一致性，以及共享会话图片展示。原生快捷键、窗口切换和系统通知仍在完整清单中单独待验。

## 已复现并修复

- 闲置超时重开会直接清空未发送的文字和图片。现在有未发送输入时保留原会话和草稿；只有空输入、没有执行中请求时才按原超时规则重开。
- 连接建立前就清空输入，连接关闭后发送状态不恢复。现在先等待连接，明确限制为10秒；连接失败或超时保留文字与图片，提示重试，不在迟到连接到达后自动发送。
- 创建会话或准备图片期间继续输入，会被旧请求清空。现在提交只消费它自身的输入快照，新编辑及新附件保留。
- 关闭渲染页面后，先前注册的连接打开事件仍可能发送。现在待发送操作有取消信号，卸载时取消等待并移除监听器。重复Enter不能并发创建同一份提交。
- 快速聊天用临时预览ID充当附件路径，模型能看图片，但历史中显示随机文件名。现在复用现有会话上传接口，提交持久文件路径、fileId和原文件名；上传失败保留草稿。已上传的附件可在连接失败重试时复用。
- Web普通图片附件缺少原生文件URL时只显示文件标记；正文内嵌图片另有读取回退。现在两者复用同一读取逻辑，通过既有认证文件桥获取缩略图；文件/服务器切换时丢弃旧结果，过期附件不读取。普通图片可用键盘和鼠标打开预览。
- 快速聊天没有停止入口。现在运行中使用同一发送按钮显示“停止”，请求绑定当前sessionId、路径与streamId，保留下一条草稿，以实际服务状态决定是否结束。

## 界面

快速输入接入主工作台的液态玻璃材质，默认14px字号；输入区最高240px或窗口高度的40%，长文本在框内滚动，避免遮挡发送按钮。关闭与添加图片使用统一SVG，关闭命中区28px，保留悬停说明。打开完整会话入口取消单独白底。准备、连接、等待回复分别显示状态，错误提供文字及可访问提示。

## 验证

四个草稿/连接问题先用旧代码复现为失败，然后实施修复。最终12个相关测试文件54项通过，覆盖闲置输入、连接失败/超时/迟到、卸载、重复Enter、准备期间新输入、持久附件引用、上传拒绝、停止绑定、跨服务器迟到图片、过期附件和既有会话交互。renderer与测试类型检查通过。

使用隔离配置、原快速聊天构建页面和本机转发服务，完成真实模型文本回复及新建48×48测试图片识别，模型正确返回主色。首次图片请求暴露随机文件名问题，修复后另建请求，并在正式Web工作台重新读取会话，确认48×48缩略图完整加载、点击画廊可打开。此路径验证共享页面/API与模型链路，不等同于原生快捷键和preload行为已验。

35行草稿实测为14px字、208px输入高度、808px内容滚动高度，发送按钮仍可见。实际停止测试第一次因回复已完成没有可点击的停止按钮，未计为停止通过；第二次在服务运行状态下点击，回复终止、发送恢复可用、下一条草稿保留。未修改正式对话、未使用业务文件、未调用外部消息渠道。

## 边界

10秒上限仅限制发送前的连接建立，不是模型回答超时；已提交后断线的结果标为未知，不擅自重发。未宣称快速聊天草稿能够跨整个应用退出持久化。当前Mac锁屏，原生窗口/快捷键/最终目视仍需补验，完整Goal不因此结束。
