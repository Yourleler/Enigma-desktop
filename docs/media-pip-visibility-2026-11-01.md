# 画中画与窗口可见性

版本：0.452.218。Web和桌面共用播放器实现。

此前播放器在主页面隐藏时无条件暂停，包括仍然显示在屏幕上的画中画。因此切到其他窗口、桌面或标签后，画中画也会停下。

现在仅当这个视频本身占用画中画窗口时，允许在主页面隐藏后继续播放。普通后台视频继续暂停；切换为非活动预览、关闭文件、移除播放器仍暂停并释放媒体。关闭画中画时，如果主页面仍隐藏，会立即暂停。不会因为另一个视频开启画中画而放行当前隐藏视频，也不会自动恢复已暂停视频。

- 覆盖隐藏窗口中的播放请求、画中画关闭、非活动预览、其他视频持有画中画及移除预览时退出画中画与清除源。renderer和测试类型检查通过。
- Web实际播放、时间推进及恢复提示可用。Chrome实际开启、退出画中画和关闭文件标签通过；内置测试浏览器拒绝画中画时显示明确说明，未宣称该宿主支持画中画。
