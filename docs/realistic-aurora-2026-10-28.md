# 拟真极光背景

界面资源版本：0.452.63。

## 0.452.65 中央光丝细调

用户反馈中央竖线过于整齐、过长。单一高频横轴采样在画面中央形成连续条纹，现改为宽光幕承载亮度，较低对比的细光丝使用缓慢变化的坐标偏移，并按局部密度在不同高度淡出。复用宽光幕噪声调节亮度，避免多加重复采样。保留幕帘、卷曲、色彩分层、玻璃开关及四种背景选择。

这是渲染参数修正，不涉及交互或持久化逻辑。验证采用实际 WebGL 编译、动态画面检查和生产界面构建，不新增与公式同构的测试。浏览器动态检查通过，局部主线程帧间隔 P95 约 9.2ms；不把此采样当作 GPU 功耗数据。

光丝修正现已并入 0.452.66，与大理石淡条带修正一起构建完成。Mac 仍锁屏，原生仍运行 0.452.64；解锁后安装最新 0.452.66，并完成原生实看，不必重复构建。

## 最终要求

深色使用像实拍一样有层次的极光幕帘，绿色主导，出现紫、红、黄的局部色彩。光弧可以卷曲、分开与展开，光丝和明暗沿光幕变化。保留玻璃折射、边缘高光及当前清晰度。浅色保留紫色材质和紫色光照。

## 公开参考

- [NOAA Aurora Tutorial](https://www.spaceweather.gov/content/aurora-tutorial)：核对原速实拍、颜色的高度分层及传播波。紫色下沿的响应可早于绿色余辉；高层红光较慢。视频实际播放并观察到光弧卷起和展开。
- [加拿大航天局 AuroraMAX](https://www.asc-csa.gc.ca/eng/multimedia/search/video/17839)：观看延时实拍，不把延时摄影速度直接照搬到工作台；观察多条弧线、明暗间歇和局部黄绿色亮边。
- [加拿大航天局颜色说明](https://www.asc-csa.gc.ca/eng/astronomy/northern-lights/colours-of-northern-lights.asp)：核对绿色常见、红色和粉紫色层次。
- [NASA Alaskan Aurora Time Lapse](https://svs.gsfc.nasa.gov/15077/)：读取说明和预览图；4K 视频加载未完成，动态判断使用前述成功播放的视频。

这是面向界面的艺术化程序模拟，不是实测空间天气或严格的光谱物理模型。黄色作为局部暖亮边处理；没有将参考视频、照片或第三方渲染代码打包进应用。

## 实现与性能边界

`AnimatedBackground.tsx` 与 `aurora-shader.ts` 生成有透视的纵向光幕。绿色、紫色边缘、红色上层及黄绿高光有独立高度和时间分布；局部卷曲与传播波改变光幕形状，不整体旋转背景。星点固定。0.452.64 起与可选大理石共用绘制器，详见[背景选择](background-choices-2026-10-28.md)。

仅夜间绘制，最多约 42 万像素、24 帧/秒；隐藏窗口和浅色暂停绘制，减少动态效果或关闭动效时保持静帧。没有网络资源请求、交互拦截或逐帧 React 更新。WebGL 不可用时使用已有 CSS 光带回退，玻璃本身不受影响。

21 项相关测试通过，覆盖隐藏/浅色停止、动效定格、绘制节流、WebGL 回退、材质偏好及资源签名；三套类型检查与构建通过。浏览器实际观察到多色光幕变化、玻璃保持开启、主题切换正常。局部界面帧间隔采样 P95 约 9.2ms，属于该 Mac 的短时主线程采样，不代表 GPU 耗电或所有设备性能。

原生已通过现有签名资源更新机制启动 0.452.63，服务/外壳维持 0.452.60。实际检查了动态深色欢迎页和浅色设置，并恢复深色；玻璃和动效保持开启，清晰度保持用户的 0%。两张不同时间的深色截图显示光幕形状及颜色变化。应用指定签名需求与更新前相同，模型和助手配置文件哈希相同；本轮启动未出现目录授权弹窗。证据保存在仓库外的本地验收目录。
