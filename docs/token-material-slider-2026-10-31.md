# Token 用量栏材质跟随滑块

版本：0.452.163。

## 原因和修改

Token 用量栏已被液态玻璃组件接管，标记为 `data-liquid="control"`，但 CSS 只给侧栏、输入框和菜单绑定了清晰度参数，遗漏普通控件。结果是滑块调到100%时，Token栏仍使用固定的低透明度填充和完整亮边。

为控件材质补上连续的填充/模糊参数，较厚一端增加遮盖并降低边缘高光。用量明细原本已使用菜单填充，现在它的亮边也随较厚一端减弱。0%保持既有颜色、透明度、模糊和边缘强度；不削弱最通透的液态玻璃效果，不修改用量计算或数字展示逻辑。

## 验证

- 10项材质偏好、玻璃生命周期与Token交互测试通过。
- 三套TypeScript检查、完整应用/服务/Web构建、签名种子验证及本地应用签名检查通过。构建使用公开依赖源。
- 实际Web操作滑块：深色0%为原10%填充、0.5px模糊和完整高光；100%为约96.4%填充、20.5px模糊和14%边缘高光。浅色0%保留原5%填充，100%约96.2%。
- 展开用量面板在100%使用98%填充，并降低亮边。关闭玻璃后使用实色背景，没有折射或伪元素；重新开启后恢复滑块效果。
- 深浅主题和输入框附近的实际视觉已核对，原始截图及构建日志保存在仓库外。
