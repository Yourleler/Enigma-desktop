# 源码关系图补齐与交互验收

## 已确认的问题

原图只展示前120个节点，未解释截断；固定三列按数组顺序排布，连线缺少方向和关系说明，也没有大图导航。查看未改动的上下文文件时，重复展示两份相同文本，容易误解为文件也发生了变更。

## 当前行为

- 所有已记录的节点都进入关系范围，显示筛选数/总数与连线数。符号、文件、仓库及角色可筛选，空结果可清除恢复；不扩大底层分析本身的覆盖范围，原记录的未展开说明仍保留。
- 按实际有向关系组织层级；循环先归组排序，但原节点和连线均保留。无关联节点仍能搜索和查看，不补造调用关系。
- 实线表示静态绑定已确认，虚线表示候选关系；箭头表示记录中的方向。选择节点突出相邻连线，详情列出来源/目标、关联类型及实际说明，再打开同一固定版本源码。静态关系不冒称运行结果。
- 支持缩放、100%还原、适应整图、空白拖动平移、可收起的缩略图、点击/拖动及键盘导航。应用内大屏模式有退出按钮和Esc返回，不新开桌面应用。
- 图中选择、筛选和视口在源码往返间保留，按阅读版本分开，最多保留24份轻量视图状态。完整节点布局不等于全量DOM；常规浏览只挂载视口附近的节点。
- 冻结上下文改为单份只读源码，保留行号、换行、查找和目标行；没有变更的内容不再展示“修改前/修改后”两份重复文本。
- 阅读图隐藏无关的模型分析工具行，窄面板将节点详情放在图下方独立滚动；大屏并排展示。按钮、搜索和节点使用已有材质及主题变量，未修改液态玻璃最大端点。

## 实际证据

使用仓库外新建Git目录：一个共享函数及135个调用文件。真实源码分析生成139个节点、79条连线；模型说明阶段只使用本地协议测试服务，不把它记为第三方模型效果。

- 界面显示139/139，无120节点截断。记录末尾节点可以按路径搜到，真实调用关系展示“调用位置/向外调用”，与保存数据一致。
- 点击源码实际打开调用文件正文与目标行，返回图后原查询和选中节点仍在。未修改用户工作目录。
- 139节点整图适应后约4%，内容边界落在1212×550px视口内；100%时仅约6–11个节点在DOM中。
- 点击缩略图移动到滚动位置7201px；End定位到14587px，等于最大滚动位置；Home返回顶部。空白拖动120px实际移动视口120px。
- 大屏退出按钮、Esc、筛选无结果/恢复、深浅主题与节点详情通过。496px侧栏中图高200px，详情独立滚动，整体内容高度与可用高度一致，没有溢出遮挡。
- 5000节点链的布局回归无递归栈问题；循环、断连节点和缺失端点分别检查，节点卡片不重叠。五个文件31项相关检查通过，三套类型检查与界面构建通过。
