# 引用草稿保存与展开编辑（0.452.260）

更新前检查发现：输入框已加入的引用仅存在于内存，切换对话会清除，重启也不会恢复。引用未进入文字／富文本草稿的恢复链路，因此过去“输入草稿没有已知缺陷”的表述不完整。

## 行为修复

- 引用按对话身份保存；首页草稿与各对话分别恢复。创建对话时转移当前首页草稿，不把创建成功当作已经发送。
- 原文、来源文件或消息、行号与原始字数进入本机恢复副本及服务草稿；屏幕选区坐标保持临时状态。
- 只有引用、没有输入文字的草稿也有效。删除引用有独立的待保存记录，刷新后不会复活旧卡片。
- 引用参加多窗口版本冲突比较；界面显示引用原文，不把它描述成空草稿。旧服务不支持引用保存时保留本机副本，新服务拒绝旧客户端无意覆盖引用。
- 发送只消费提交时的引用快照。等待文件读取时新加入的引用、另一对话的输入，以及发送失败时的内容均保留。
- 放大编辑器同时展示引用和草稿恢复提示；移除引用不会清掉编辑文字。移除按钮补充可访问名称。

文件格式继续使用输入草稿版本1，增加可选引用字段。持久化清单、兼容性说明和源码指纹已同步，没有新增豁免。回退旧服务前必须保留完整草稿备份，因为旧服务不能理解引用字段。
