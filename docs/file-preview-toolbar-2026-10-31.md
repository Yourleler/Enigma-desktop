# 文件预览工具栏整理

版本：0.452.153。日期：2026-10-31。

## 行为

- 工具栏左侧仅保留文档类型或章节目录；右侧集中放置复制、文件操作、查找和问号帮助。
- HTML 明确显示“复制源码”，复制原始 HTML 内容，包含样式和脚本，不包含预览器注入的辅助代码。Markdown 显示“复制 Markdown”；代码与纯文本分别显示“复制代码”和“复制全文”。悬停提示及问号帮助说明范围；选择部分内容仍使用系统复制快捷键。
- 跳转行、自动换行、折叠和展开收进“阅读选项”。在窄面板中适当收起文字，保留图标、可访问名称和悬停说明。
- 正文查询输入框靠右显示，限制宽度，不覆盖文档。编辑查找的关闭按钮扩大至24×24。
- 修复HTML查找只搜索外层容器的问题：在隔离的网页内部搜索可见文字，支持跨行内格式匹配、计数、上/下一项、高亮，以及网页内的⌘/Ctrl+F。脚本、样式、隐藏内容不参加匹配。
- HTML搜索仅传递查询与数字结果，不改变原来的sandbox与CSP，不新增文件访问权限。父页面只接受对应预览窗口与当前请求的结果；结果最多2000项，达到限额时明确提示。

## 验证

- 43项相关检查通过，覆盖导航、原有封面入口、HTML隔离、查找结果限制、复制文本、服务端路由及样式约束；最后的布局修正另有专项复测。三套TypeScript检查通过。
- 实际Web验证：新建HTML中3处可见匹配（包含跨strong标签文本），隐藏文字与脚本排除；下一项为2/3，网页内部快捷键打开查询；复制内容与原始文件逐字一致，未包含预览辅助代码。
- 实测Markdown高级阅读菜单、编辑查找、Escape关闭；420px窗口无水平溢出，全部工具保持在同一行。
- 最终原生验收与安装保留结果待补录。

实现基于已有React、CodeMirror和浏览器消息/文本高亮能力，未引入第三方源码或新依赖。
