# 打包预览资源与 Web 升级缓存

日期：2026-10-30，完整候选 0.452.126。正式应用未替换。

## 发现与修复

独立服务包原先只从主页面追踪 JS/CSS，预览子页面的 HTML 虽然被复制，其相对引用却没有遍历。结果是表格子页面缺少主模块和样式，导入线程 Worker 也缺失；PDF 子页面的样式存在同类问题。完整桌面版使用独立 renderer 归档，因此此前在源码和完整桌面包中的通过证据没有覆盖这条独立服务路径。

资源收集现在从被打包的 HTML/JS/MJS/CSS 按文件所在目录解析相对依赖，支持子页面的父目录引用、CSS import 和基于 import.meta.url 的 Worker。显式子页面依赖缺失时构建失败；路径仍限定在公开 assets 树，未把桌面主页面、源码映射或私人文件混入服务包。

静态服务器曾对稳定名称的主题脚本、语言包和 service worker 返回一年 immutable 缓存。现在只有哈希文件和版本化阅读器目录使用长缓存，稳定 URL 采用 no-cache 和内容 ETag。启动 HTML 为旧稳定脚本和主题链接增加版本参数，避免用户已有的一年缓存继续命中；动态主题带同一版本号，语言读取主动重新校验。

## 实际验证

从打包后的 hana-server 启动，工作目录和配置都在全新测试目录，明确不设置 HANA_RENDERER_DIST。其页面只能使用包内 Web 资源。

- 表格曾实际显示“导入组件无法启动”；修复后成功打开两表文件、切第二表、选 A1:B1，并复制出实际单元格文本。
- 完整 PDF 阅读器、两页正文和样式正常显示；Word 默认纸张、正文与 100% 缩放正常。
- 在同一测试端口从旧服务换到新版，再刷新同一个浏览器页。页面显示版本 0.452.126，脚本与主题 URL 带新版本参数，表格仍可加载。
- 新版主题资源返回 no-cache 与 ETag，相同 ETag 请求返回 304；哈希 Worker 返回 200 且继续使用 immutable 缓存。
- 新增回归先在旧实现失败，修复后通过。全量回归 **11,792 项通过、7 项跳过，0 失败、0 未处理异常**；三套类型检查、边界检查与完整构建通过。
- 完整 Mac 包通过 seed 验签、本地签名、实际启动及插件启停重启检查。Mac 仍锁屏，原生网页焦点、预览组合、打印/画中画等尚未点击验收，正式应用没有替换。

这次验证证明独立服务的预览资源路径，不代表所有浏览器、文件格式和原生操作都已验收。继续保留 README 中的剩余项目。
