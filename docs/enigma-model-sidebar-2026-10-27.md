# 模型配置与侧边栏修复（2026-10-27）

本轮对应用户反馈：配置模型失败、侧边栏收起与展开分离、展开时卡顿。本地已安装版本为 0.452.43。

## 问题与处理

- 0.452.40 用户实际实例在文件历史注册 `fs.watch` 时阻塞，进程采样停在 `FSEventWrap::Start → uv_fs_event_start → open`。监听移入 Worker 后，0.452.41 可以启动，但界面随后发起的资源订阅再次在同一系统调用阻塞主线程。最终把文件历史与资源订阅统一接入 `lib/isolated-file-watcher.ts`：原生监听注册独立执行，5 秒未就绪给出诊断；关闭有界，保留文件变化回调、资源订阅共享与退订。
- 0.452.42 原生窗口初始化还暴露工作台列目录的同步 `readdirSync` 阻塞，采样停在 `ReadDir → scandir → open`。`LocalFsProvider.list` 改为异步目录读取与文件 stat；慢目录只延迟自身请求，避免阻塞设置与其他接口。
- 文件历史读取失败仅在 ENOENT/ENOTDIR 时记为删除，避免将权限/其他访问错误误认为文件已被删除。资源监听的异步错误进入原有诊断，不暴露主机路径。
- 主对话和频道侧栏去掉内部重复收起按钮和悬停浮动预览，顶部固定位置的同一按钮负责来回切换。补充展开状态和受控区域语义；收起内容设为 inert，避免键盘进入不可见区域。
- 开合不再对列宽逐帧动画；固定宽度内层使用短位移和透明度过渡，玻璃折射也绑定内层，避免反复生成中间宽度的纹理。深浅主题和关闭动效的机制保留。
- 移除 SidebarLayout 阻碍 StrictMode 重挂载的初始化锁，修复快捷键监听被清理后不再注册，并清理待处理 resize 定时器。
- 首次保存供应商时，验证失败提示保留后端具体原因，不再只显示泛化的验证失败。
