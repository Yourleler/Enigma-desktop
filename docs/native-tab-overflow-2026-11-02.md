# 标签末端修复与原生补验

界面版本0.452.254，桌面宿主与服务保持0.452.251。使用隔离配置与既有测试文件，正常应用在验收结束后恢复；没有向用户会话发送测试内容。

## 发现并修复的问题

原生文件固定为最右侧标签后，滚动提示仍挡住关闭按钮。Web对照中，标签条可视宽345、内容宽515、滚动位置170，已在末端，但右箭头仍可交互；关闭按钮中心实际命中了箭头。

玻璃选择动画的伸展会扩大浏览器计算的滚动宽度。现在边缘判断、选中标签定位和箭头滚动按实际标签布局计算，不把装饰动画计入内容范围。玻璃材质与滑动动画保持原样。点击已到末端的箭头时也重新核对边缘状态。

新增带真实标题栏挂载的回归场景：装饰溢出仍有26像素、最后一个标签已经完整出现时，右箭头必须消失。修复前该用例失败；修复后标签、玻璃选择与标题栏共22项检查通过，完整类型检查和界面构建通过。未重复运行此前已通过的全量回归。

## 本轮实际操作

- 原生窗口从1512像素宽缩至960和700；窄窗展开右侧文件面板、切回左侧对话，未看到输入区域挤压重叠。回到宽窗可双侧展开。
- 点击测试目录名称，系统文件管理器打开对应目录，确认测试文件可见，随后关闭本轮打开的目录窗口。
- 原生打开测试源码文件并固定为同级标签。254直接点击最右侧关闭按钮成功；通过加号重新打开，文件内容保留。拖动后文件标签位于时光机之前。
- 时光机的“恢复代码”和“助手纠偏”可以切换，说明能展开，明确上下文纠偏、代码恢复和另开方案的区别；无检查点时也说明当前限制。

分隔线拖动尝试没有取得足够的连续帧和位移证据，不标为动态同步通过。纯悬停和跨系统窗口拖入也不由上述点击、固定和调序结果代替。
