# 对话目录、预览与补载位置验收

本轮对应 A07、A09、A10、A44 中的对话导航链路。测试使用隔离服务和 60 轮人工准备的对话内容，没有向用户会话或模型发送测试消息。

## 问题与修复

- 悬停/聚焦预览保存了旧的 anchor 对象；回复更新后仍显示旧预览，锚点删除后还可能残留。现按消息标识读取当前预览，不再缓存旧正文，消息消失时关闭。
- 上层为避免反复测量位置，只比较用户输入，忽略回复片段变化。现将预览数据与几何测量分开：回复片段保持更新，位置测量仍按消息身份和实际布局变化触发。
- 目录过滤只搜索前 600 字预览。现搜索完整的已加载提问，结果片段围绕命中词生成，并使用已有深浅主题高亮色。搜索跳转定位到词语，普通刻度点击仍定位轮次开头。
- 补载早期消息时，浏览器可能已执行滚动锚定，代码又加了一次新增高度，导致正文跳动。现记录可见消息及相对位置，只修正实际偏差；补载不被误认为新回复而跟随到末尾，失败的旧位置快照也会清理。

原生纯鼠标悬停未在本轮冒称通过。组件鼠标事件检查与 Web 键盘预览分别记录。

## 实际验证

1. 初始载入最近 25 轮；其中一条长提问的命中词在前 600 字之后。目录输入“紫苑203”仍得到该轮，结果片段与正文命中都有显眼高亮。
2. 目录搜索跳转后，长提问末尾词处于正文视口内。普通导航的跳转和减少动态效果路径另有回归。
3. 滚动导航刻度，导航自身 scrollTop 从 189 到 0，正文 scrollTop 始终为 12324，两个滚动区独立。
4. 从 25 轮补载到 50 轮，正文参考元素 top 从 161.63 到 161.41 像素；再补齐 60 轮后为 161.23。目录保持打开、筛选词保留，编号随已加载轮次正确更新。
5. 浅色和深色目录高亮均实测。键盘从第 58 轮移动到第 57 轮，预览包含时间、输入与回复，Esc 关闭成功。

73 项关联检查通过，覆盖长输入、预览更新、删除锚点、补载浏览器锚定、定位、历史索引和贴底滚动。前三项缺陷在修复前的反例失败，修复后通过。三套类型检查与界面构建单独核对。
