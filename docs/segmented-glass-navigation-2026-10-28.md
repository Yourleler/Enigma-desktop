# 固定主导航与连续玻璃滑块

版本 0.452.54。

用户反馈切换到频道后，聊天/频道按钮组从右上角跳到了中央；同级选项也没有完整呈现从上一项移动到下一项的玻璃滑块。

原因：标题栏有标题时将 ChannelTabBar 放在右侧，无标题时则在另一位置创建组件。页面切换改变了组件位置并重建滑块；此前动效主要是短时伸展，无法弥补节点被替换造成的中断。部分同级控件只切换底色。

- 标题栏始终在右侧保留同一组主导航，不随对话标题有无改变挂载位置。
- 统一 GlassSelection：每组只保留一个玻璃层，按当前选项的实际坐标、宽高移动，文字保持稳定；支持尺寸变化、换行和无有效选中项时隐藏。
- 接入聊天/频道、右侧文件/工作台、用量范围与统计分组、外观菜单主题、设置主题/字体、变更阅读、时光机、技能/配方及工程内容标签。
- 保留材质光带、选中态、340ms 移动和短时伸展；关闭动效或开启减少动态效果时立即切换。

验证：66 项相关回归通过，三套类型检查通过。浏览器切换聊天→频道→聊天时，按钮组坐标始终为 x=1354.984375、y=6.5，宽度 111.015625；滑块 id 保持一致。采样观察到当前 transform 与目标 transform 不同且动效 running，最终回到 idle，证明存在实际中间帧。用量范围、统计分组和主题均完成点击验证；关闭动效时 transition 为 0s。

桌面包已本地签名校验并安装，原生窗口确认加载 0.452.54。已点击聊天→频道→聊天，频道页截图确认按钮组仍在右上角；返回聊天后位置不变。旧应用备份保留，模型配置哈希不变；没有发送测试对话。
