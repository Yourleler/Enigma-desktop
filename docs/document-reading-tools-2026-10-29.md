# Markdown 与代码阅读工具

日期：2026-10-29 至 2026-10-30；候选版本 0.452.122。继续复用完整开源组件，保留原工程、权限、文件版本和保存路径。

## 使用结果

文档顶部常驻目录、查找/替换、跳转行、自动换行和折叠/展开入口。复制、预览/编辑、封面和截图移入同一行；窄窗口自动换行。目录独占可收起区域，支持筛选 1–6 级标题和实际章节跳转；搜索框占独立区域，不覆盖正文。

编辑模式使用 CodeMirror 原生搜索面板，提供下一项/上一项、选中全部、大小写、整词、正则表达式、替换和全部替换。跳转行使用其原生命令，支持绝对行、相对偏移与百分比。输入框增加 input 事件兼容，避免直接填值或辅助输入后仍按旧替换内容执行。

代码区按语言名/文件名加载已安装的语言包，实际启用语法着色、括号匹配和折叠；不是只有行号的纯文本区域。自动换行不改文件内容，切换时保留原先可见行；浅色使用清晰的紫/绿/蓝配色，深色使用较亮配色。

阅读模式用 CSS Custom Highlight API 标记文本范围，支持跨粗体/斜体查找，不改 React 管理的正文节点。保持原有旧浏览器回退；新高亮需要支持该 API 的浏览器。当前原生高亮最多记录 2000 处，后续还要补界面的明确截断提示。

## 实际修复的可靠性问题

- Web 文件保存后仅版本变化也会重建编辑器，导致搜索面板和撤销历史消失。现按文件身份区分，版本更新保留编辑器；不同预览文件使用独立编辑器实例。
- 全局预览查找会抢走聊天输入中的快捷键。现限定在预览焦点内；编辑区由 CodeMirror 自己处理。
- 阅读高亮曾因正文重绘消失；现用原生范围高亮并在内容变化时重算。
- 阅读/编辑模式原来没有落盘，刷新后总回编辑。现明确保存模式并在工作区恢复时应用，代码阅读位置也接入原有位置保存。
- 错误百分号编码的章节链接可使诊断抛异常。现显示可读链接问题，文档继续可用。

## 公开技术来源

- [CodeMirror 搜索接口](https://codemirror.net/docs/ref/#search)：使用已安装并锁定的 `@codemirror/search 6.6.0`，MIT，保留许可证并随 renderer 打包。
- [CodeMirror 语言接口](https://codemirror.net/docs/ref/#language)：复用 LanguageDescription、语言包、foldGutter 与折叠命令，无另写语法解析器。
- [CSS Custom Highlight API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API)：用 DOM Range 与 CSS 设置高亮。浏览器能力不足时走已有回退，不宣称老浏览器具有相同跨格式能力。
