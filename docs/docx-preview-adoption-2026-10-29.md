# Word 预览：复用 docx-preview

状态：0.452.99 候选已实现，Web 实测通过。Mac 锁屏阻止原生复核，正式应用仍为 0.452.91；不把候选或 Web 结果写成正式安装完成。

## 实现

- 使用公开的 [docx-preview 0.4.1](https://github.com/VolodymyrBaydalka/docxjs)（Apache-2.0，Copyright Volodymyr Baydalka）直接渲染 DOCX 版式，复用分页、页眉页脚、脚注、图片、表格与样式能力。
- 版式与文本阅读可切换。文本转换按需执行，打开/后台刷新只读取元数据，避免先转换再解析同一份文档；原文件版本变化后更新版式与文本。
- 提供适应宽度/缩放、页码跳转、文档搜索、原文件下载。版式搜索用 CSS Highlight Range 覆盖跨加粗等样式边界的词组；文本阅读也能查找和上下跳转。阅读位置/缩放在当前应用进程内最多保留 64 个文件版本。
- 文档在 `sandbox="allow-scripts"` 的不透明来源 iframe 内渲染。信任的解析库与消息桥打包到本地资产，不授予文档同源权限。禁止网络、外部字体、嵌入 HTML、表单提交及可执行链接；父页面只接受当前 iframe 和随机通道的消息。
- DOCX 展开前检查压缩包目录和大小。错误、超时、取消、文件版本变化和切换连接时释放旧任务；失败后可重试、文本阅读或系统打开。界面显示可理解的中文错误。
- 上游完整许可证、原始库头与 JSZip 的 MIT 许可随本地阅读器资产保留；没有复制私有参考代码。

## 实测

新建的 OOXML 文件包含两页、页眉页脚、中文彩色标题、表格、脚注、原创 SVG 图示以及跨样式词组。Web 真实检查确认：

- 两个页面、两个页眉、两个页脚、一张表格和实际解码的图片出现。
- 搜索“跨样式搜索”匹配跨普通/加粗文本；“第二页”有两个结果，上一项/下一项可切换；文本阅读搜索高亮不会被状态重渲染覆盖。
- 跳至第二页后收起/重新打开，滚动位置保留；版式/文本来回切换正常。
- 适应宽度时 1280 px 和 420 px 窗口无横向溢出，控件无越界；深浅主题背景、工具栏和文字清楚。
- 下载 DOCX 落盘字节与原文件一致。修改新建测试文件后，已打开的文本与版式都能看到更新内容。
- 结构损坏的 DOCX 在版式/文本两条路径都报告错误，提供重试，不伪装成空白成功。
- 38 项预览/读取/刷新回归、三套类型检查及边界检查通过。另 26 项 Web 应用回归通过，覆盖本轮补回的设置入口及访问范围。

独立测试文件、截图和日志保存在仓库外，未改用户文档。原生版式加载、原生下载和 PDF 完整阅读器打印仍待可用的桌面状态继续核验。

## Web 工作台相邻修复

实测发现 Web 应用一直隐藏设置按钮且没有设置快捷键。现在仅向拥有 `settings.read` 的会话或本机所有者显示入口，并增加 Cmd/Ctrl+,；已有服务端访问控制不变。真实 Web 设置打开、深浅主题切换及返回文档通过。

## 边界

docx-preview 并非 Word 的完整排版引擎；自动分页、复杂域、修订和特殊绘图可能不同。当前是阅读/预览，不在侧栏编辑原 DOCX，不宣称 OCR、完整 Word 或像素级一致。遇到特殊文档保留原文件与系统应用入口。
