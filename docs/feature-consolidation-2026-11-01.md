# 功能精简与保留依据

本清单针对当前代码和已做交互验证；不会把名称相近的功能直接视为重复，也不会以删除功能绕过验收。界面默认继续面向个人编程、多目录项目和任务协作。上游版权与许可保留。

| 原有能力 | 与当前功能的关系 | 处理 |
| --- | --- | --- |
| 供应商页旧用量面板 | 已没有生产入口；当前设置中的历史用量页支持时间、模型、用途、状态、对话、日期分组和分页，底层用量账本相同 | 删除四个无引用组件/辅助文件及专属CSS，移除只为旧实现服务的测试；底层账本、API和当前统计测试保留 |
| 个人记忆与工程记忆 | 前者记用户偏好，后者有项目来源、版本和适用范围；不能用一种覆盖另一种 | 保留不同作用域，默认不将候选自动变成事实 |
| 多助手身份与管家工人 | 身份提供独立配置，管家提供任务分工、预算、依赖及结果整合 | 保留；通过同一工作对话入口展示 |
| 助手群聊与任务编排 | 群聊是多身份会话，任务编排有依赖、权限、验收和整合约束 | 保留群聊作为可选沟通能力，不把普通群聊结果冒充独立验收 |
| 协作流程与管家 | 协作流程执行预定义脚本；管家根据目标动态组织任务 | 保留可选流程，脚本执行仍受沙箱、并发与预算限制 |
| 定时任务/目录巡检与持续观察 | 前者决定何时触发，后者监控正在执行的目标与故障恢复 | 保留；目录巡检说明已收进“目录选项”，不当作所有对话的共享背景 |
| 文件书桌与右侧文件面板 | 相同目录文件不能在两个主面板重复占空间 | 已统一为文件标签，同框预览和固定独立标签；旧独立布局保持兼容读取 |
| 旧CSV编辑器与当前源码编辑器 | 同一文本格式的重复编辑实现且旧实现存在选区/保存差异 | 此前已合并到统一编辑器，CSV保留正常文本、搜索、撤销和保存 |
| 外部消息连接 | 是远端消息渠道，不能被本机浏览器或电脑插件替代 | 保留可选接入，缺少账号时明确提示；没有擅自登录或外发消息 |
| 快速聊天与主工作区 | 快速入口用于短输入，主工作区承载目录、预览和长任务 | 保留；快捷键和系统窗口仍需原生最终复核 |
| 角色卡/技能包/插件 | 分别携带助手配置、可复用工作方法和运行能力，不等同于背景交接 | 保留各自用途与权限边界；背景交接不自动安装插件 |
| 图片/音视频生成与文件预览 | 前者依赖供应商，后者读取已有文件 | 保留可选生成能力及通用预览；没有凭证时不宣称生成链路通过 |

## 本轮可核对的精简

旧统计实现四文件共747行，专属CSS区段约588行，及三个只服务旧实现的测试已删除。全库生产引用检索确认没有入口；新用量页真实116条请求在日期、用途和对话筛选下与独立核对一致，翻页仍保留全范围合计。旧组件原本未进入生产入口，因此不把删除代码行数当作同等的运行内存或启动速度收益。

同时统一用途名称与模型输入控件名称：代码审查、工程任务、助手任务不再显示内部英文标识；同名/未命名对话附带更新时间供区分；凭证保存、连接验证和模型发现有各自准确的回执。

## 尚需继续验收

本轮77项附带功能检查覆盖临时目录下群聊CRUD、流程执行/恢复/预算和模拟通知/连接边界。UI确认无凭证时明确提示，没有发送任何外部消息。它们不证明每个外部平台实网送达、原生快速聊天窗口或全部媒体生成供应商通过。最终按[完整清单](full-feature-acceptance-2026-10-31.md)继续，不据此结束目标。
