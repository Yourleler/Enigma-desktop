# 侧边代码变更与双视图

日期：2026-10-30。交付版本：0.452.140（包含0.452.139的侧边补全）。

## 使用目标

用户在普通 coding 对话里也应直接看到仓库变更，不需要先连接另一套工程菜单。右侧仓库标题下常驻“代码变更”，列出仓库名、分支、文件数和增删行数；多个已登记仓库分别列出。点击后直接进入平级的“智能阅读 / 全量 diff”，可切换工作区或暂存区来源。

之前这条路径只存在于已连接工程的顶部“变更”入口，普通对话缺失侧栏提示。本次保留原工程的提交/MR/任务地图等工具，新增普通对话直达入口，复用同一个 ChangeReadings 与 Changes 展示组件。

## 行为

- 普通对话从服务端会话工作目录寻找 Git 根，已连接工程使用已登记仓库；客户端不能传任意根目录。
- Git 统计包含暂存、未暂存和未忽略新文件；二进制/过大文件单列，不伪造文本行数。统计失败显示原因，隐藏不完整的数字。未初始化提交可用。
- 工作区视图相对 HEAD；暂存视图读取 index。差异和智能阅读共同引用冻结版本，当前文件变化不会改写旧视图。
- 静态阅读按职责、调用关系与源码锚点组织，明确不等于模型解释或验收结果。
- “打开当前源码”走当前会话的授权读取，和冻结片段分别展示。拒绝路径越界、逃逸符号链接及已排除的敏感文件。
- 快照保存到应用自己的配置目录，不往源仓库写工程配置，不执行暂存/提交，也不变更会话模型策略。
- 阅读面板自动拓宽；窄窗使用既有抽屉与让位逻辑。生成过程有状态、取消和失败重试。另一会话或连接的迟到结果不会覆盖当前视图。
- 非 Git 文件夹显示明确说明，生成文件仍可在“对话文件”预览；没有 Git 基线时不把文件列表冒充版本差异。
