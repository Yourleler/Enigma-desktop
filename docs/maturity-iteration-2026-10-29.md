# 使用体验与稳定性继续打磨

状态：执行中。基线为已推送的 0.452.82 界面与 0.452.81 服务。本轮目标是完成已确认缺口及相邻流程的修复、实际交互验收和安装，每轮验证后提交并推送开发分支；不以“已测场景通过”等同所有细节无缺陷。

## 验收范围

1. Markdown 链接：本地及 Web 工作台跨文件章节定位、中文/编码标题、重复打开同一章节、缺失章节反馈、已有阅读位置与切换竞态。
2. 预览体验：统一媒体/PDF 工具栏的视觉、键盘和状态反馈，保留搜索、缩放、播放、错误恢复等已有能力。检查长标题、窄窗口和深浅主题。
3. 浏览器工作区：减少双层标签与常驻按钮的拥挤，提升状态文字可读性，检查下载、弹窗、嵌入页面及网页/文件切换，明确兼容边界。
4. 电脑权限：把插件加载、允许操作、系统授权与应用确认放在可理解的同一流程中；准确显示未检查与未启用，保留用户当前的关闭设置。
5. 回归与交付：使用新建测试文件/网页/原生窗口及隔离配置实测；核对模型任务与取消接管不回退。安装前后保护模型配置、会话、草稿，更新验收记录，提交并 push；不发布 release、不启用 Actions。

## 第一轮：章节定位与权限入口（0.452.84）

已实现：

- 本地和 Web 工作台的 Markdown 跨文件章节定位，保留中文/编码片段；自动进入阅读模式、滚动到目标并短暂高亮。原有滚动恢复不覆盖新请求，重复点击会产生新的定位请求。

### 草稿恢复与保护补修

安装前发现既有首页草稿为空，用户确认未手动清空，已按要求恢复并保存。此次丢失没有足够日志精确归因，不能声称已经复现根因。

代码核查确认并修复两个独立风险：编辑器切换可编辑状态会发送非正文 update，现不再将它持久化；同一草稿的请求按顺序提交，避免较慢的旧清空晚于新内容落盘。连接身份变化后旧排队写入和旧读取结果不进入新连接。13 项草稿/会话身份回归通过；原生隔离启动和设置往返保留测试草稿。后续仍需覆盖断线、重载、多窗口并发与实际退出期间的未提交输入。


安装核对：正式应用已启动 0.452.91 界面，服务保持 0.452.81。原草稿按用户要求恢复后，以此为安装基线；安装前后 5 个受保护配置/会话/草稿文件哈希一致，实际窗口确认模型与草稿保留。当前 Goal 继续进行，下一项是草稿断线、重载、多窗口与退出持久性，不宣称所有成熟度问题已经消失。
