# 图片预览复用 PhotoSwipe

状态：0.452.118 界面候选已签名并在独立配置中启动，宿主/服务使用此前的 0.452.110 完整候选。正式应用仍是 0.452.91 界面和 0.452.81 服务。Mac 锁屏阻止原生点击，本轮未请求用户输入或改锁屏设置。

## 实现

直接使用 [PhotoSwipe 5.4.4](https://github.com/dimsemenov/PhotoSwipe) 的缩放、拖动、捏合和幻灯片切换。依赖固定版本、MIT 许可证随界面产物保留；没有复制私有参考代码。

- 图片侧栏与媒体画廊共用同一个 PhotoSwipe 适配层，删除原自写的变换状态、鼠标拖动和重复舞台实现。
- 侧栏提供适应面板、原始像素大小、放大/缩小、滚轮缩放、双击切换、下载、系统打开/位置（本机可用时）和画廊入口。嵌入场景按面板坐标修正鼠标和滚轮位置，不假定是全窗口。
- 画廊保留同组图片/视频、页数、前后切换、键盘导航、关闭后返回焦点与“在侧栏查看”。宽图和小图按真实尺寸处理，不默认放大小图。
- Web 工作台通过当前目录的授权内容路由提供邻居，不再只打开一张图片。目录来源随当前文件保存/恢复，切到另一根目录不复用错误文件列表；不构造远端机器的本地路径。
- 混合列表中的视频保留系统播放控件。离开当前视频、页面隐藏、关闭画廊都会暂停；销毁时显式移除媒体来源并释放，避免上游清空事件监听后漏掉回收。
- 失败文件可原位重新加载，错误状态和文件名可见，其他文件仍能前后浏览。图片读取取消会释放资源，慢结果不会重新挂到已关闭的预览。
- 浅色与深色工具栏使用应用颜色；棋盘背景帮助看清透明图片。小窗口标题单独成行，按钮不挤出面板；保留可见文字、焦点描边和状态说明。动效遵从关闭动效/系统减少动态设置。

## 实测范围

使用新建 SVG 网格图、小图、宽图、损坏图以及新建测试视频，没有改用户原文件。

Web 真实交互已确认：

1. 大图适应面板，原始大小显示 100%；双击、工具栏与滚轮能改变实际缩放；拖动后图片位置实际变化。
2. 原图下载落盘字节与来源一致。
3. 当前目录 6 个媒体文件组成画廊，图片和视频可用按钮/方向键切换；刷新后恢复的侧栏仍能打开同组画廊。
4. 损坏图片有重新加载入口；修正该新建测试文件后，点击重试显示实际新尺寸 800×400。
5. 视频实际播放，切换下一项后从播放中变为暂停，播放位置停在约 0.04 秒；单元回归额外覆盖关闭时主动卸载视频。
6. 从画廊把宽图放回侧栏，仍显示同一文件；画廊关闭返回工作台。
7. 420 px 侧栏和画廊工具栏、前后箭头完整可见。深色主题、设置往返和透明棋盘背景已查看。

92 项媒体、来源、工作台恢复相关回归通过；三套类型检查与边界检查通过；签名界面归档校验并启动候选通过。原生鼠标/触控板、焦点/设置遮挡，以及实际安装仍须继续验收。
