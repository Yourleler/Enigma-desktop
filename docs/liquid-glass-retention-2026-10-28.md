## 公开资料与设计取舍

苹果的材料指南把 Liquid Glass 定位为导航和控件层，强调与内容层区分，避免一层玻璃叠另一层玻璃。WWDC 的设计说明进一步区分 Regular 与 Clear；后者不适用于任意文字背景。[材料指南](https://developer.apple.com/design/human-interface-guidelines/materials)、[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。

当前苹果公开 macOS 页面强调提高折射一致性和对比度，并提供由清透到着色的调节。这里采用同一原则：清晰度调节影响导航、菜单、输入控件的底色，正文不参与形变。[macOS 设计更新](https://www.apple.com/sg/os/macos/)、[更新说明](https://support.apple.com/en-mide/127257)。这些是所检索到的官方页面描述，未将其等同于本机系统版本或原生 API 能力。

社区解读主要争议是透明背景是否会与文字争夺注意力。Digital Trends 认为可调透明度为可读性提供了必要余地；512 Pixels 引用无障碍作者 Steven Aquino 对 Clear/Tinted 控制的观察，强调美观选择与无障碍需求并不完全等同。二者是观点，不能作为定量可用性测试。[设计评论](https://www.digitaltrends.com/computing/apple-made-liquid-glass-adjustable-which-says-plenty-about-liquid-glass/)、[无障碍评论](https://512pixels.net/2025/10/aquino-clear-tinted-liquid-glass/)。未采纳未找到原始测量依据的具体失败比例或对比度传闻。

苹果自定义玻璃资料强调交互时的移动、融合和形变。此工程使用 Web/Electron 的移动选中层和短时形变，属于受其启发的实现，不声称使用了 SwiftUI 原生玻璃渲染器。[自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。

## 实现

| 要求 | 当前实现 | 验证 |
| --- | --- | --- |
| 用量记录上限可配置 | 设置→用量统计→历史记录保留；100–100,000 条，默认 5,000 | 实际保存、服务重启后恢复；无效值不允许保存 |
| 保留范围准确 | 上限随账本保存；降低上限前显示移除条数，保存失败不改内存记录 | 路由/账本测试，摘要覆盖范围随上限变化 |
| 右侧栏统一 | 单一导航材质、内部文件内容底色、状态分区；取消各块互不相干的实色卡片 | 深浅色截图；文件区和状态可同时看到，侧栏无水平溢出 |
| 切换玻璃动效 | 右侧标签、聊天/频道、主题选择共享移动玻璃选中层；短时轻微伸展和亮度变化 | DOM 采样观察到 running→idle 与中间 transform/scale |
| 可读性 | 玻璃清晰度滑块，浅色辅助文字加深，极光集中在边缘，正文不变形 | 低/高着色切换、主题切换和关闭动效实测 |
| 界面图标 | 30 个主要操作图标使用 Lucide 0.468.0 公开 SVG；标题栏同时统一 | 保留 ISC 许可证及来源；构建检查 |
| 系统图标大小 | Dock 图标增加 80/1024 留白；菜单栏模板为 18pt，主体约 14pt | PNG 边界、18/36px 双倍率资源已核对；用户在实际系统中确认大小正常 |

历史上限统计的是模型请求，而非用户轮次。更改上限不会删除聊天内容，也不改变服务商的账单；提高上限不能找回之前已移出的用量。现有账本兼容读取，不更换数据目录。

## 验收证据与边界

- 83 项账本、权限、侧栏、材质和设置回归通过；35 项持久化检查通过；后续 16 项界面集成及 14 项最终修复验证通过。不同批次有重复文件，不能相加作为唯一用例总数。
- 三套类型检查通过。PNG 主图透明边界为 `(80,80)–(943,943)`；菜单栏 18px 图的可见边界为 `(2,2)–(15,15)`。
- 隔离验证把 126 条用量改为上限 100，保留 100 条；服务重启后返回 `maximum:100, retained:100`，页面恢复为 100。
- 右侧栏实测宽度 238px、scrollWidth 238px；可切换标签并展示文件列表。一次浏览器采样的 180 帧 P95 为 9.6ms；该数据仅描述当前设备与场景，不是所有设备的性能承诺。
- 调色时按 WCAG 普通文本 4.5:1 基准检查候选颜色；透明背景下仍需按实际背景测试，未宣称全界面通过 WCAG 认证。[WCAG 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。
- 用户数据与模型配置保持不变，测试使用隔离目录。GitHub Actions 保持关闭，不发布、不合并。

## 0.452.52：大容量用量统计

用 100,000 条受控测试记录验证上限时，发现无变化的自动刷新也会重新复制、分组并排序整本账本。首次摘要约 423ms，未变化的第二次摘要原来约 419ms。现按账本内存修订号缓存最多 12 个筛选组合，同样数据的未变化刷新约 0.07ms；首次统计仍需完整计算。此数值来自本机的单次受控样本，不代表所有设备。

新增请求、成功修改上限和清空账本会增加修订号并清掉旧统计；保存失败不更改版本。不同会话、筛选、时区和账本实例分别处理；返回值独立复制，调用方修改不会污染缓存。19 项相关专项通过，三套类型检查通过。

安装包资源已核对：18px 与 36px 模板图、Lucide 许可证均与当前源码一致。原生验收已于解锁后完成。


历史阻塞已解除：此前连续三个 Goal 轮次因 Mac 锁屏受阻；用户解锁并允许操作后，接续完成原生验收，没有重做已通过的迁移或构建。
