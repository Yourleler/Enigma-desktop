# 恢复白天紫色光带与夜间极光

版本 0.452.53。

用户反馈 0.452.51–52 的玻璃效果比此前参考版本弱，尤其浅色模式。原因是上轮同时移除了中部光带，并提高了导航/控件底色和模糊；即使仍有折射滤镜，背景差异也被压平。

- 恢复参考版本的紫色弧形光带、细亮边和渐变；深色恢复青紫极光。
- 降低导航与工具栏/输入框的叠色和模糊。清晰度 50% 时，控件底色为 14%、模糊 1.5px；导航底色 35%、模糊 5px，保留背景可辨的折射。
- 清晰度仍可调整，菜单采用独立、较高的底色以保持文字可读。文件区减少白色叠层，沿用新的右侧分区和状态布局。
- 保留新图标、选中态、切换动效和用量功能；本次未改模型或历史记录。

浏览器已对照用户参考图检查深浅主题并保存截图，19 项材质、动效、主题和设置回归通过。桌面包已本地签名校验、替换并启动；原生窗口确认加载 0.452.53，浅色光带、工具栏和输入框折射已实际查看。旧应用保留在仓库外，模型配置未改。
