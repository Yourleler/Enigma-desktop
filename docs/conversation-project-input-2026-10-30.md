# 运行反馈、项目背景与图文输入

日期：2026-10-30。版本：0.452.135；预加载协议6、服务协议8、数据版本1。以下实现基于本项目需求、现有代码与公开上游组件，未引入第三方私有代码或资料。

## 最终使用效果

### 看得懂正在做什么

工具行使用统一线性图标和简洁动作名称，例如“写入文件”“运行命令”，保留目标路径、错误和状态。等待提示改为轻量波形动画，并显示实际阶段：等待模型、思考、生成内容、准备工具调用、执行工具和后续处理。

此前模型在生成长工具参数时，只有执行开始才显示工具记录。现在从流式调用开始就报告“正在准备工具调用”和工具名，明确此时工具尚未执行。超过15秒无新进展会说明仍在等待，状态连接过期则说明进度待确认。定时心跳不被当成有效进展，也不会据此宣称卡死或完成。

Token 数值在已收到的相邻测量之间平滑变化；结束、换轮与关闭动效时直接对齐准确值，不预测没有收到的输出。保留估算标记、真实用量校正及历史统计。

### 项目真正成为共享背景

新对话与现有对话顶部有明确的“对话归属项目”，可选择已有项目或“未归属项目”。全局新建默认为单独对话；从项目内新建则保留项目身份，并采用其默认目录。已有历史按目录归类的行为保留，单独对话在项目视图中另列。

“共享背景”可维护项目说明、已确认笔记、默认目录和协作目录。每次模型请求读取当前项目的最新背景，实际附加在当轮上下文中；移出项目后的请求不再注入原共享背景。编辑有长度上限和版本冲突检查，避免较早打开的窗口覆盖新内容。更改已有对话归属不搬动文件。

这里共享的是明确维护的背景和笔记，不是把所有会话原文混在一起。原工程插件继续负责多仓库关系、工程资料、代码智能阅读和工程记忆。协作目录声明不授予额外文件访问权限，也不把共享背景保存当成已完成跨仓库协作。

### 图片和文件进入正文

粘贴、选择或拖入的附件转为输入框中的内联卡片，可放在文字之间，显示图片缩略图/文件名并支持删除。附件上传期间继续输入时，原光标位置随编辑映射，避免上传完成后跑到错误位置。

发送时保留“前[图片1]中[文件2]后”的顺序，并为模型提供附件身份对应表和实际图片数据。历史记录独立保存干净正文和附件顺序，刷新后不会把内部映射内容混进正文。Web补齐文件上传及图片读取适配，普通文档无需伪装成图片；既有上传大小与访问限制继续生效。
