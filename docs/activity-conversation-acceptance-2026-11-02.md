# 后台结果转为对话与运行记录核查

本轮延续任务计划验收，检查“运行记录 → 展开过程 → 转为普通对话 → 继续处理”的实际链路，对应完整清单 A03、A42、A44。

## 已复现的缺陷

- 活动对象刷新会把用户选中的分类切回第一个有内容的分类。
- 运行中的后台会话仍可点击转为对话；失败仅写日志，没有界面回执。
- 转移文件使用直接重命名，同名目标存在时可覆盖既有对话。新增反例在旧实现下失败。
- 原“展开过程”过滤掉全部工具调用与结果，只剩模型文字，无法核对实际行为。
- 转换后活动条目被移除，用户无法从原记录再次找到结果；新对话标题还可能直接使用包含调度说明的首条输入。

## 修复

- 按助手记住选择的分类；列表、配置与过程读取核对原连接和请求序号，旧查询不覆盖新连接。新到达的实时活动不会被迟到列表覆盖，同 ID 的不同助手记录分开保存。
- 巡检开关有明确名称、状态和错误说明，提交期间防重复。旧配置查询不回滚已经确认的开关修改。
- 转为对话只允许已结束的记录，提交期间防重复，失败就近显示且原记录保留。文件转移采用不覆盖目标的操作，失败恢复也不覆盖新出现的源文件。
- 服务端对同一活动的同时转换合并处理。转换成功后保留活动条目和目标文件标记，后续点击直接打开已有对话；不会反复创建副本。新转换的对话使用任务名称作为标题。
- 工具调用、结果、状态和时间按实际记录展示；隐藏思考不纳入展示。工具文本超过 12,000 字符时明确标注截取，可进入完整对话查看。展开控件使用小箭头，避免默认实心三角和无标签的复制按钮。
- 活动转入对话期间若连接改变，不继续操作新连接；会话列表读取也增加同样的归属校验。

## 实际验证

测试使用上一轮真实计划任务产物的隔离副本，未操作用户的正式后台记录。

1. 展开活动过程，原 write、read、文件登记调用及回执均出现，读取结果可展开核对。
2. 在隔离目录创建同名对话作为冲突样本，点击转为对话后得到明确错误；独立读取确认目标内容和原后台文件均未改变。
3. 移走冲突样本后重试，普通对话显示完整原要求、回复、工具和文件入口。继续发送仅仅读文件的任务，真实模型正确返回 `SCHEDULED_OK_247`，原文件未改。
4. 返回运行记录，已转换活动仍在，按钮显示“打开对话”；再次展开可看到原结果与后续读取。切到空的巡检分类后刷新，所选分类保持不变。

272 项会话、活动、路由、存储及消息处理检查通过，最后巡检竞态与文本投影另有 8 项通过。覆盖同时转换、重复请求、同名保护、运行中拒绝、助手隔离、迟到列表、失败反馈、标题设置、截取提示与隐藏思考过滤。

原生窗口仍因 Mac 锁屏未验，本轮 Web 证据不替代原生 Office、悬停、系统通知及全目标剩余范围。完整目标未完成。
