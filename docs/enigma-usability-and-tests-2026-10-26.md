# 界面、功能流程与完整测试

2026-10-26。当前目标：继续美化黑色极光/白色淡紫界面，调整布局，梳理功能并完整测试。本页继承上一轮外观整改，保留其他 Agent 的工作和原项目验收范围。

## 实际修复

| 问题 | 当前行为 |
|---|---|
| 更多功能平铺，不知道用途 | 按任务与协作、知识与交付、运行与质量分组，每个入口有简短说明 |
| 计划、资料、成果、审查空白 | 显示用途、下一步及实际可用的创建入口；不再只有“暂无记录” |
| 计划等页面的查询框实际无作用 | 仅在资料、记忆、技能和文件查找等支持查询的视图保留输入框 |
| 阅读工具仍使用旧式嵌套浮层 | 使用统一视窗浮层，长菜单可滚动，不被内容面板裁切 |
| 代码追踪结果充满内部字段 | 直接呈现定义、导入、调用位置、片段和静态确认状态；完整原结果保留为折叠证据 |
| 模型分工保存同时改当前和默认值 | 明确选择仅当前会话、以后新任务、或两者；默认仅当前会话，切换会话后的旧表单拒绝应用 |
| 管家默认模型可能是undefined/undefined | 从真实当前模型或可用模型列表初始化，提交前检查范围和原会话身份 |
| 示例跑完但文档状态没有更新 | 执行后刷新当前文档面板，显示新的实际结果 |
| 记忆和管家查询重叠、旧响应串到新面板 | 旁路只保留一个在途查询；切会话/卸载取消读取，迟到回复不更新新会话 |
| 标签刷新回到第一个，加载状态遗留 | 保存选中标签及面板打开状态，兼容旧标签数组；新会话清空旧加载/表单状态 |
| Web刷新总回到新对话 | 桌面与Web启动入口都按原生会话ID恢复已保存视图；只从当前服务端可访问列表解析，不存权限/模型历史；主动新建会话清除旧选择 |
| Web宽屏左右栏不能同时打开 | 仅窄窗保持左右抽屉互斥；宽窗按可用空间显示两侧 |
| Web与工程抽屉叠加两层遮罩 | 工程抽屉打开时由工程层拥有遮罩与焦点，Web不再重复覆盖 |
