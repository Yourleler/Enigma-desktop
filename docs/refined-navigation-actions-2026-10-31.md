# 轻量操作图标与对话导航

界面版本：0.452.166。宿主和服务仍为0.452.164，本次只更新已签名的renderer资源。

## 改动

- 移除侧栏操作组的白色底块、统一容器圆角和整体阴影；图标直接融入对话行。置顶、归档、更多统一为15px图形，桌面命中区域24px，触控扩大至44px。
- 用简洁细线图钉替换原复杂路径，归档改成中性色圆角归档盒，更多使用真正的三点图形。悬停、聚焦、按下和置顶状态各自保留轻微反馈。
- 三个按钮使用明确的独立提示，支持鼠标悬停和键盘聚焦；不依赖浏览器title，也不再与整行说明抢占提示。
- 对话导航宽度42px→28px，刻度视觉厚度3–6px→1.5–2px，刻度间距24px→16px；区域高度不超过260px且随可用空间缩减。长对话仍逐轮保留、可独立滚动。
- 移除导航光晕与粗焦点胶囊。只对当前位置和交互中的刻度做轻微着色、加长；计数平时隐藏，交互时显示。
- 预览宽度400px→320px，保留时间、用户输入和助手回复，内容可内部滚动。文本预览使用普通阅读材质，不额外添加液态折射亮边。

本次按[项目界面设计原则](interface-design-principles.md)落实，公共依据为其中列出的Apple官方文档，没有引入外部图标代码或图形资产。

## 验证与安装

- 66项导航、侧栏操作和提示回归通过，包含新增的三个动作提示实测；三套TypeScript检查通过。
- 实际Web确认操作组背景完全透明、图标统一中性色、提示内容正确；置顶/取消置顶和更多菜单可用。25轮导航保持全部入口，独立滚动位置可从235回到0。
- Web实测导航约28×220px，显示时间和输入/回复的预览宽320px。浅色与深色分别核对。
- 正式Mac应用已通过签名资源更新载入renderer 0.452.166，保留原应用签名与服务0.452.164。原生逐个键盘聚焦确认三个操作提示，刻度定位和内容预览正常；没有在正式会话执行归档或改名。
- 正式Web已核对引用新renderer资源。原模型、草稿、图片与会话数据保留；10个保护文件中9个哈希完全一致，偏好文件仅workspace_ui_state因查看会话/返回首页而更新。首页图片草稿已在原生重新确认。
- 原始截图、完整备份、签名更新包和文件核对记录均放在仓库外。GitHub Actions保持关闭，未发布或合并。
