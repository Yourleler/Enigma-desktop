# 输入框排版与图片固定预览

实现版本：0.452.173；实际交付界面：0.452.174；宿主与服务使用 0.452.169。本轮调整共享 Web/桌面界面，不修改模型后端。

## 期望效果与实现

- 正文默认 15px、输入文字 14px，内容和输入栏上限统一为 760px。侧栏分组、项目子项和对话行采用更一致的留白与字重；空输入框保留适当的编辑高度，长草稿逐步增高后内部滚动。
- 顶栏不再放置静止的“开始 HH:mm”。运行中仍显示运行计时；完整开始时间保留在任务面板和计时提示中。历史每轮时间记录不变。
- 输入框展开按钮没有常驻色块、边框和阴影，仅显示轻量箭头；悬停或键盘聚焦可发现，保留操作提示。
- 鼠标悬停缩略图时短暂预览；点击后固定图片，背景淡化、模糊，整个输入框移到聚焦层继续编辑。图片始终在输入框上方，两者保留间距。
- 图片关闭按钮放在图片左上角，鼠标移入图片或键盘聚焦时出现；触屏始终可见。前后切换按钮紧邻图片边缘，按输入文档里的实际顺序切换。
- 输入变多时图片按可用高度等比例缩小，不盖住输入区。看图与展开编辑两种状态下均支持插图；看图时 Enter 换行，发送通过发送按钮。Esc 优先关闭菜单，再退出图片模式。
- 编辑器、附件节点和整个输入区域通过持久宿主移动，不重新创建。固定、取消固定、展开、收回以及异步附件上传都保留光标与草稿所有权。背景内容在聚焦阶段不可被键盘误选。

## 验证与界限

测试在隔离配置和新增文件中完成，没有发送模型任务或修改正式对话内容。

- 58 项图片节点、固定/取消、轮播顺序、菜单 Esc、上传书签、输入历史、粘贴、草稿同步及计时回归通过。
- Web 实测三张图片的插入、固定、前后切换、展开后追加图片、退出和重载恢复。输入增高时，测试图片从 457px 高缩至 319px，三个附件保持顺序。
- 固定图片并展开编辑曾导致图片被挤至顶部；已通过独立的布局标记修复，并加入回归。
- 图片按当前窗口剩余空间展示；不会删除或压缩原文件。过长草稿在输入区内滚动，图片仍留有可操作区域。

420px 窄窗、横向与纵向图片、深浅主题均已实操，窗口无横向溢出。原生插图中发现尺寸观察回调反馈提示，改为逐帧合并和仅变化时写入；原生复测已验证实际尺寸变化、系统选择器插图、切图与展开编辑，修复后日志未再次出现该尺寸反馈错误。已随 0.452.174 安装至正式应用并核对 Web 资源。原生追加第三张图片、展开/收回、切图与退出均通过，原模型、对话和草稿保留。截图、测试配置和恢复备份保存在仓库外。
