# 模型设置与同类表单布局修复

2026-10-27。针对模型分工截图中的单选项下拉、控件错位与过长表单。

- 尚未进入工程会话时，“应用范围”显示固定说明，不再提供只有一项的下拉框；已进入会话时保留当前、新任务和两者三种范围。
- 规划、执行和复核各自拥有一个分组，模型与思考力度同行；窄于 560px 时自然变为单列。
- 标题和保存区固定，只有字段区滚动；不会为了找到保存按钮滚过整个表单。
- 新任务默认分工可以读回；切换范围保留各自草稿，读取失败时禁止覆盖默认值，支持重试。
- 没有思考能力或只有一个有效等级时显示固定值，缺少模型时明确引导添加；输入请求上限有独立的可访问名称和单位解释。
- 模型分工、管家方式、操作表单和确认表单使用一致的下拉控件。菜单在弹窗之上显示，Escape 先关闭菜单，第二次才关闭表单。
- 创建管家采用两列数量设置，模型列表可筛选和滚动；没有可写仓库时显示只读说明，保存区固定。

验证包含当前与新任务范围保存、默认值重开、草稿切换、服务切换保护、读取失败重试、控件层级与键盘行为。浏览器实测三种执行方式、角色选择、保存重开，以及 420×680 实际页面视口；宽窗同组两个控件顶边相等，窄窗菜单保持在视口内。
