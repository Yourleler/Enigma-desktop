# 长文件差异的阅读位置与查找

本轮继续 A11、A17 验收。界面版本为 0.452.226，宿主与服务仍使用 0.452.222。完整 Goal 尚未完成。

## 实际问题与修改

在新建验收仓库比较两个固定提交，1200 行 TypeScript 文件的第 3、1100 行发生变化。原生界面展开全文并查到第 1100 行后，切换单栏跳回文件开头。

原实现只记录单个编辑器的滚动像素；双栏实际滚动的是共同父容器。现在按源码位置、选择范围及查找条件恢复，覆盖单双栏、换行、相同内容折叠、文件与面板往返。新的源码跳转仍优先生效；同一个旧跳转不会覆盖后续手动阅读。

阅读缓存用冻结版本、仓库、文件共同定位，正文改变时拒绝沿用旧状态；最多保留 40 项、合计 200 万字符，退出界面进程后不承诺保留。

同时修复长内容被固定内部高度裁切的问题。查找栏改放在两栏共用的顶部区域，避免右侧增加一段高度后，左右相同行不再对齐；底部“标为已读”与正文不再重叠。切换按钮保持键盘焦点。

采用 CodeMirror 的公开 `panels`、搜索状态、文档坐标及 `scrollIntoView` API，未修改依赖源码。公开参考：[视图与面板 API](https://codemirror.net/docs/ref/#view)、[合并视图](https://codemirror.net/docs/ref/#merge.MergeView)、[搜索](https://codemirror.net/docs/ref/#search)。
