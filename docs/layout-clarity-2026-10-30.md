# 侧栏动效、顶部收纳与名称说明

版本：0.452.141。日期：2026-10-30。

## 解决的问题

- 左右栏过去先把宽度瞬间变为零，再对已被裁掉的内容做透明动画，导致收起与展开不同步。现在两侧内联布局统一180ms宽度/透明变化；浮动布局统一180ms位移/透明变化，关闭期间保留定位，结束后释放。标题栏图标同步表达打开/关闭方向，遵循减少动态与关闭动效设置。
- 窗口变窄、恢复页面或切换主页面时不应主动弹出浮动侧栏。恢复只计算可用空间；浮出由用户明确点击或明确打开工程内容触发。浮层改用现有玻璃材质，去掉原来的不透明灰底。
- 目录标题过去只是文本。桌面端点击打开当前本机目录的系统文件管理器；Web及远程目录点击返回目录文件根视图，不把远程路径交给本机系统执行。
- 顶部工程目录、项目归属、外观、时间重复占据多行。项目归属、共享背景、工程工具和时间现在合并为一条紧凑信息栏；外观移到标题栏。普通1280px Web布局实测信息栏41px高，420px窄屏65px高，时间与运行记录保留。

## 名称和用途

| 入口 | 实际用途 | 本轮变化 |
|---|---|---|
| 目录文件（原“工作台”） | 浏览当前工作目录里的全部文件 | 标签、搜索提示改名，并说明和“对话文件”的区别 |
| 对话文件 | 本对话上传、生成或关联的文件 | 保留现有入口 |
| 目录巡检说明（原“文件夹说明”） | 保存自动巡检的目录处理要求，开启巡检后读取；并非每轮聊天共享背景 | 收入目录标题旁的“巡检说明”；默认不单独占一块；展开后说明生效条件，编辑内容保留 |
| 项目共享背景 | 项目内对话下次模型请求读取的背景、笔记及目录索引 | 保留在项目归属旁，可直接打开 |
| 助手群聊（原“频道”） | 多个助手参与的群组讨论及助手私聊，与普通coding任务分开 | 主入口改名、补悬停说明，说明模型用量及可选性质 |
| 工程工具 | 仓库、计划、时光机、阅读、验收、旁路与模型分工 | 顶部改为紧凑菜单，原能力保留 |
