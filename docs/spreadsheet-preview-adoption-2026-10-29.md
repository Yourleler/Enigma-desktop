# 交互表格预览与 CSV 保存修复

状态：0.452.110 完整候选已构建、本地签名、seed 验签和启动验证。正式应用仍为 0.452.91，原生点击与安装需继续验收；本页不把 Web 或组件测试当作桌面交付证明。

## 实现与来源

直接复用 [Univer 1.2.0](https://github.com/dream-num/univer) 的开源 Sheets Core、查找界面与渲染内核（Apache-2.0）。XLSX 由现有 [ExcelJS](https://github.com/exceljs/exceljs) 在本地 worker 读取并映射到 Univer 数据模型；CSV 使用 [PapaParse](https://github.com/mholt/PapaParse)。主题 XML 使用 Saxes；库许可证随构建保留。

Univer 官方文件导入导出属于另一套产品能力，这里没有使用商业导入/打印服务，也没有把文件上传到外部服务。调用范围与 API 依据为 [安装说明](https://docs.univer.ai/guides/sheets/getting-started/installation)、[权限接口](https://docs.univer.ai/guides/sheets/features/core/permission) 以及固定版本包内类型和源码。

- 交互表格代替旧 HTML 截断表格。支持多工作表、选区、复制、查找、缩放、冻结行列、合并单元格、行高列宽、隐藏行列/工作表、字体、底色、边框、数字与日期格式。
- 读取现有公式和文件保存的结果，不主动重算。没有缓存结果的公式明确标注；CSV 保留前导零和等号文本，不执行为公式。
- 保留隐藏表的数据和隐藏状态，界面说明总表数及隐藏表数。富文本局部字形、内嵌图片、图表、透视表、宏等未完整导入时说明边界，不宣称与 Excel 像素一致。
- 上游查找默认可能限制在合并/多单元格选区。本项目入口明确查找整个工作簿，高级查找可调整范围、查找值/公式、大小写和整单元格匹配。
- XLSX 为只读预览，编辑应使用系统应用。保留 CSV 的原有编辑能力，新增“表格预览 / 编辑 CSV”切换；原文件下载保持原始字节。
- 工作簿在独立 iframe 与 worker 中处理，解析工作不阻塞聊天主界面。文档输入不获得宿主 API，不加载外部网络资源；超时与损坏显示错误并可重试。上限为 20 MB 压缩文件、80 MB 展开结构、100 张工作表、25 万有值或样式单元格；超过上限会明确拒绝，不静默截断。

## 实测与修复

使用原创新建 XLSX：1203 行、公式缓存、冻结行、合并标题、日期/百分比、隐藏工作表。CSV 含空行、前导零和带引号多行字段。

Web 实测已确认：

1. 第 1203 行可定位，数值格式和公式原文可查看；两张可见工作表切换正常，第三张隐藏表保留并计数。
2. 全工作簿搜索有真实结果；区分大小写和范围使用上游查找界面。复制日期/百分比得到显示文本，而非原始日期序号。
3. 选区定位、关闭再打开恢复末端选区、缩放、深浅主题和 420 px 窄窗口控件可用；高级查找浮层不越界。
4. 双击编辑被只读权限阻止；提示改成“只读预览，请用系统应用”，避免让用户联系不存在的创建者。
5. 下载 XLSX 后核对字节与原文件一致。修改新建 XLSX 后，已打开预览能定位到更新后的内容。
6. 损坏 XLSX 显示明确错误和重新加载入口。
7. CSV 预览保留前导零、等号文本和空行；编辑单元格并切回预览，实际文件已保存，空行和带引号多行字段保留。

CSV 验收额外发现两项旧缺陷并修复：

- 原编辑表格的解析/重建会丢空行和超出标题列数的数据。改用 PapaParse 并保留原始行结构，只替换实际修改的单元格；CodeMirror 编辑后的换行仍采用其文本规范化方式。
- 文件内容接口返回精确小数毫秒，而 ResourceIO 写入校验使用截断毫秒，导致未修改文件也冲突。统一为 `stat.mtimeMs`，仍严格拒绝旧版本写入；没有取消冲突保护。补了精确版本往返和真实外部改动拒绝的测试。

补充反向验证：测试公式的缓存刻意设为 999，而重算会得到 82；实际复制结果为 999.00，证明预览保留缓存。

80 项相关导入、组件、CSV、文件服务/路由回归通过；三套类型检查和边界检查通过。机器路径、真实测试回执、截图和备份保存在仓库外。
