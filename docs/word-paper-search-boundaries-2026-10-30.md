# Word 默认纸张与搜索边界

日期：2026-10-30。界面候选 0.452.124，兼容现有 0.452.122 宿主/服务。原正式应用未替换。

## 修复

- 极简 DOCX 没有声明 section 纸张参数时，上游渲染成约 127×20 像素的小块。现在只为缺失的显示参数补 A4 与 2.54 cm 页边距，并在页面底部说明；不写回原文件。已有横向纸张、尺寸、显式零边距保留。
- Word 和 Markdown 阅读搜索读取第 2001 个结果来区分“恰好 2000 项”和“还有更多”。超限时显示 `2000+` 及“已显示前 2000 项，请缩小查询范围”，仍可在已显示结果间导航。旧浏览器的标记回退同样限制结果数量。
- Word Unicode 大小写搜索保持原文偏移；长段落按实际 Range 位置滚动，避免跳到整段中间。Markdown 原生高亮也按匹配词位置定位。
- 通用悬停提示不再处理 iframe/object/embed 的文档标题。标题保留为无障碍名称，避免整页文档上方出现重复悬浮标签。

## 真实验证

全部使用新建本机文档和隔离配置：

| 场景 | 结果 |
| --- | --- |
| 未声明纸张 | 未缩放页面 794×1123 像素，宽 210 mm，边距 25.4 mm；适应宽度/100% 正常 |
| 明确横向与零边距 | 1123×794 像素，padding 0 pt，无默认回退标记 |
| 完整两页文档 | 页眉、图片、表格、脚注及两张 794×1123 页面保留，未触发默认参数 |
| 下载原文件 | 下载 DOCX 与输入字节完全一致 |
| Word 搜索 | 2001 个 needle 显示 2000+，2000 个显示精确 2000；含 Unicode 前缀的 Match/MATCH 定位正常 |
| Markdown 搜索 | 2001 项显示截断提示，2000 项不误报；高亮与导航可用 |
| 悬停与标题 | iframe title 保留，页面上方不再出现文档名称提示块 |

53 项相关回归、三套类型检查、边界检查和界面构建通过。界面已签名并在隔离候选中启动；原生点击仍未验收。

本轮还运行了全仓测试，发现 **37 项失败及 18 个未处理异常**。这些集中在历史契约/登记更新、样式规则、语言包、模型并发及测试浏览器环境，尚未全部修复；详见[全量回归收尾清单](full-regression-followup-2026-10-30.md)。不能把本页定向通过当作整仓通过。

## 范围与复现

`node scripts/create-word-geometry-fixtures.mjs <新建测试目录>` 创建默认纸张、横向零边距及搜索边界文档；原有 `create-docx-preview-fixture.mjs` 提供包含版式要素的原创测试文档。将它们放入隔离工作台按上述步骤操作。

复用锁定的 docx-preview 0.4.1，仅增加显示默认值和宿主搜索/标题适配。分页、复杂域等仍遵守上游能力边界，未承诺等同 Word 排版。原生组合验收、全量回归修复及正式安装继续进行。
