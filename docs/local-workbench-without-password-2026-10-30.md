# 本机工作台直接进入

日期：2026-10-30。版本0.452.136，服务协议9。

删除工作台用户名/密码登录页、设置中的密码设置与清除入口，以及对应密码写入路由。旧密码不再用于浏览器登录；模型供应商的API凭证与其他设备的配对凭证仍各自管理。

本机用户直接打开普通工作台URL即可进入。客户端先检查现有会话，必要时向本机服务自动建立HttpOnly浏览器会话，不要求复制密钥、不要求额外命令、URL中不放令牌。本机连接失败时提供重新连接按钮，而非退回密码表单。另一台设备仍使用配对流程。

自动建立会话同时验证实际loopback socket、明确的localhost地址、同源Origin、Fetch Metadata和专用请求头。远程请求、跨站请求、空Origin、伪造Host和缺失transport证明均不能自动取得本机身份。普通API的鉴权没有移除；工作台不能被外站嵌入，HTML预览采用隔离origin，避免预览脚本继承本机工作台身份。

98项相关回归通过，包含本机自动进入、cookie恢复、配对保留、移除密码路由、设置入口、跨站与远程拒绝、HTML预览。三套类型检查、完整构建及签名seed验证通过。实际用新建隔离配置直接打开无令牌的本机URL，未填写任何凭证即可进入；设置中的密码项不存在。

完整应用、服务与Web资源已安装为0.452.136；再次打开正式本机URL直接进入，无密码或配对输入框。原生设置页确认无密码项，原HTML预览仍正常显示。旧应用与用户数据在仓库外备份；模型配置保留，已有会话原记录逐条保留，用户更新后的新消息和草稿继续保留。不开启Actions、不发布、不合并。
