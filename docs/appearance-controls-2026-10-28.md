# 外观按钮与当前状态

版本：0.452.50，2026-10-28。

用户反馈：主题入口是普通半圆字符，缺少按钮反馈；浅色和深色按钮无法看出哪个正在使用。

- 入口改用统一线条的太阳/月亮图标，常驻显示“外观 · 浅色/深色/自动”。边框、悬停、按下、展开和键盘焦点均有反馈。
- 菜单使用浅色、深色、跟随系统三个选项，唯一选项有描边、勾选和“使用中”，通过 aria-pressed 暴露真实选择。自动模式额外说明当前实际深浅色。
- 状态由已应用主题和保存的选择共同决定，监听主题属性与存储变化，避免从其他入口切换后仍显示旧状态。
- 液态玻璃、界面动效改成整行可点击开关，滑块与“已开启/已关闭”同步；延用设置页的材质偏好。
- 菜单切换后保持打开，便于核对结果；Escape 关闭并归还焦点。同步时防止重复提交，失败明确提示。

验证：三套类型检查、19 项已有主题/菜单/设置回归通过。浏览器实测浅色、深色、跟随系统、两种开关启闭、Escape 焦点返回及刷新恢复；深浅色已截图核对，菜单控件无文字溢出。测试使用隔离配置，不修改用户主题和模型配置。

桌面包 0.452.50 已签名校验并替换到本地应用，旧包保留，模型配置哈希不变。Mac 当前锁屏，原生窗口本轮未点击验收；解锁后重新打开应用使用新版。
