# 工作标签的溢出边缘

版本：0.452.219。用户要求工作面板顶部的标签在空间不足时柔和隐去，避免文字被直线截断。

标签条现在按实际滚动位置显示左右渐隐和轻微模糊，提示该方向还有内容。边缘箭头平滑滚动标签，不切换当前面板；到达边界后隐藏，无溢出时移除遮罩。箭头没有额外底框，深浅主题共用现有材质与文字色。系统设置为减少动态效果时使用即时滚动。

键盘方向键、Home与End继续选择标签，并把选中项带到渐隐以内。窄窗和侧栏宽度改变后重新核对位置。滚动监听采用被动事件，只有边界状态变化才更新组件，不添加持续计时器。

实测还发现恢复后的文件标签顺序只保存了一部分，首次点选可能把文件移到其他恢复标签前。现在先保存完整的显示顺序再切换；拖动调序仍沿用原机制。

## 验证

- 23项标签与顶栏回归通过，覆盖起点/中间/终点箭头、溢出消失、滚动不切换面板、键盘选中项避开遮罩、恢复文件首次切换不调序，以及原有关闭/恢复、拖动调序和浏览器状态保留。
- renderer与测试类型检查通过。
- 真实Web在1280、960及460px核对深浅主题。960px末端定位实际滚动到2307px，等于最大滚动距离，右箭头消失；点选前后标签顺序一致。窄窗箭头没有挤到搜索、添加和展开按钮上。
- 边缘实际使用3px模糊与34px渐隐；选中标签避开28px边缘。玻璃最通透端点和背景设计未改变。

原生219实测向右滚动后任务标签完整显示、右箭头消失，回到起点恢复右侧渐隐；选中任务后内容与标题一致。完整应用已签名安装，服务与界面均为219。69项保护文件无缺失，模型、会话及草稿保留；每日状态、版本标记与布局状态按启动更新。交付包7,820个文本文件按既定私有模式扫描无命中。此项修复不代表完整功能Goal已经完成。
