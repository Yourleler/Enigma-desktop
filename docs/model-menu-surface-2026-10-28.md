# 模型菜单白块与名称裁切修复

版本 0.452.55。

用户截图中的菜单白块来自滚动容器承载的玻璃背景：列表滚动时，绝对定位的材质伪元素也随内容移动，露出与外框错位的内层矩形。底部模型按钮使用固定 24px 高度、1 倍行高和 overflow 裁切，导致部分字形上下边缘不完整。

- SelectWidget 分为固定玻璃外框和独立滚动列表。背景、折射及描边只属于外框；滚动、键盘导航和分组内容位于内层。
- 选项支持长名称换行；列表首尾保留内边距，键盘 Home/End 能完整滚到目标行。
- 模型/思考组合控件和模型按钮提高到至少 32px，名称使用 1.5 倍行高和上下留白；可用宽度扩大到 240px，过长名称仍可悬停查看全文。

验证：26 项菜单、模型选择、输入区和材质回归通过，三套类型检查通过。受控 34 个模型、两个供应商分组实测：列表从 0 滚到 933px，玻璃外框 scrollTop 始终为 0，top/height 不变；最后一项完全处于滚动可视范围内。模型按钮高度 32px，名称行高 20px，上下各 6px。顶部和底部截图已保存在本地验收目录。

桌面版已签名校验并安装，原生窗口确认加载 0.452.55。实际模型列表顶部供应商标题完整；键盘 End 到最后一项时，最后一行完整可见，材质保持单一连续外框，没有滚动后错位的白色内框。模型按钮文字上下留白正常。验收后关闭菜单，未选择其他模型；模型配置哈希不变，旧应用已备份。
