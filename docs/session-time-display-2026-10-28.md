# 消息时间与常驻运行计时

2026-10-28，本地版本 0.452.47。

- 用户消息在鼠标移到消息附近时显示“发送于”；助手流式消息显示“开始接收”，完成后显示“收到于”。展示月日、时分秒，完整时间和本地时区说明可悬停查看。键盘聚焦消息操作时也可看到；触屏直接展示。
- 对话顶部常驻显示对话开始时间、当前运行类型、状态、时长和本轮/目标/协作开始时间。无需展开用量面板。窄窗口允许换行。
- 普通对话计时使用宿主运行快照；对话开始来自原生会话文件头，重开或切换对话不会把开始时间改成当前时间。断线显示最后已知状态，未知终态不伪装成持续运行。
- Goal 对应宿主循环任务，跨轮等待计入历时；显式暂停期间不累计。时长账本随循环状态保存，恢复后继续使用原开始时间。
- 管家从本身开始工作时记录起点；工作对话并发期间显示持续协作历时，工作间隔包含在跨度内。遇到没有终态的中断任务显示待核对，不据进程存活推断完成。
- 流式消息重建保留原接收开始时间；完成时使用服务端已落盘的消息时间，避免刷新前后一个显示开始、另一个显示完成。

验证：真实受控流式回复计时、完成后停表、发送/接收悬停、页面重载时间保持；真实循环启动/暂停/停止后核对账本；专项测试覆盖权限、会话切换、时区/长时长、暂停恢复和管家无子任务时的计时。所有实测使用隔离目录；未把测试模型配置写入用户目录。


最终验证：类型检查通过，消息/流式/路由/循环等专项通过；32 项持久化检查通过。真实受控普通回复为 24 秒；循环运行后暂停，两次读取均为 29,013ms；管家本身无子任务时计时可用，两轮之间保持协作起点。最终重载检查确认显示到秒的消息时间、助手完成时间及对话/协作计时不变。开始接收时间与收到完整回复的时间明确区分。

桌面包已本地签名并更新，原生窗口确认使用 0.452.47；旧包保留在仓库外，用户模型配置未改。相关截图、测试日志和隔离运行记录保留在本地验收目录，不随仓库分发。


## 0.452.49：每轮回复末尾保留时间

- 原顶部计时只有最近一次运行快照，下一轮会替换，不能作为整段对话的历次记录。现在顶部保留对话开始时间，只展示仍在运行、暂停或待核对的任务，不再显示已结束的最近一轮。
- 每轮最后一条回复下方常驻“本轮历时、开始、最后回复”。时间直接来自原生会话记录；刷新、切换、下一轮不会覆盖前面的记录。旧历史有对应时间时也可恢复，缺失或时间顺序异常时明确显示“未记录”。
- 历时定义为该轮输入到最后回复的跨度，含等待与工具执行。它不是纯模型计算时间，也不是整个对话的累计时间；最后回复不意味着目标已经完成。停止或异常只显示已记录范围，不虚构成功状态。
- 历史接口在分页前关联真实输入，后台输入与可见用户输入分别处理。执行过程折叠时，时间留在折叠区外；展开后不重复。
- 验证：8 个相关测试文件首次 214 项通过，新增异常时间用例后相关 16 项复测通过；三套类型检查通过。受控流式真实运行两轮，两轮均为 9 秒；第二轮生成时第一轮记录仍在，刷新后两轮原始起止秒数及历时一致。桌面包 0.452.49 已本地签名校验并替换，旧包保留。Mac 锁屏，原生窗口本轮未点击验收；已验证同源 Web 界面与完整服务端链路。
