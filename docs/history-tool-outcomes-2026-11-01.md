# 历史工具结果与等待确认区分

版本：0.452.215。

任务取消后，部分工具没有来得及写入最终回执。历史投影正确地将其标为unknown，但工具卡把unknown显示为“待确认”，过程摘要还将其计入“尝试未成功”。这会让用户误以为任务还在等待批准，或者把缺少证据当作已知失败。

现在这类条目显示“结果未记录”，说明历史缺少最终回执，应核对实际结果后再重试。使用次要文字颜色，与红色失败状态区分。折叠摘要单独显示“n项未记录结果”，有缺失回执时默认展开便于检查。实际待批操作继续由确认卡表示；没有擅自将缺回执改写为成功、失败或已取消，也没有修改原历史数据。
