# 浏览器界面状态恢复与材质统一

## 已确认问题与修正

- 独立窗口初始状态查询可能晚于实时事件返回，旧快照会覆盖已经打开的新标签。现在实时事件优先，过期初始回复及错误不再回写。
- 同一面板内，较早命令的返回可能覆盖后续原生事件或新命令。独立窗口和侧边浏览器都核对事件版本、请求顺序与面板归属；网页弹窗回复同样受保护。
- 较早页面的错误可能显示在新标签；关闭查找后的异步完成也可能把焦点送到另一个页面。错误与查找按窗口、对话、标签和页面范围隔离；关闭查找只在原页面仍有效时恢复焦点。
- 独立窗口“放回侧栏”和下载预览的失败没有统一处理。现在就近显示错误，后续原生状态可清除错误，操作不会产生未捕获拒绝。
- 网页输入弹窗的中文输入法Enter与重复Enter可能误提交。增加输入法检查及同步防重入，失败后仍允许重试。
- 断开连接后停用查找输入和翻页，显示连接状态，不把旧匹配数继续当作当前结果。
- 独立浏览器HTML缺少主界面的基础样式，导致部分间距变量未定义。补齐基础样式；工具栏、地址框、查找框和网页弹窗使用共用材质变量，清晰度两端不变。

## 验证范围

68项相关检查通过，覆盖初始查询与原生事件乱序、命令与标签切换、对话范围变化、弹窗重复提交/输入法、查找与焦点、下载入口、页面取消、宿主读取和弹窗处理。最终断连控件修正又通过17项定向检查；三套类型检查与界面构建通过。

另在仓库外构建网页视觉样本，直接使用本项目的浏览器工具栏与独立窗口组件，**宿主事件为受控模拟，不能充当原生网页操作证据**。实际点击“新页面状态”再返回旧快照，地址保持新页面；深浅主题无横向溢出，共用基础间距存在。清晰度两端的工具栏与查找框模糊分别为0.5px和20.5px，背景同样变化。样本及临时服务器已关闭。

本轮不修改浏览器执行权限、系统鼠标或网页会话存储。此前原生表单、frame、下载、上传、拖放及取消证据继续按原报告保留；Mac仍锁屏，新版独立窗口与侧边原生交互待补验。完整Goal尚未结束。
