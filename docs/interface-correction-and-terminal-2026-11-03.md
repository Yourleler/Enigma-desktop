# 界面可读性修正与内置终端（269–271）

## 依据与复审范围

依照公开的 [Impeccable Operate 指导](https://github.com/pbakaus/impeccable/blob/4f956490f0056ae1ff5ea80372cf56e83c001d3c/.agents/skills/impeccable/reference/operate.md)与 [Craft floor](https://github.com/pbakaus/impeccable/blob/4f956490f0056ae1ff5ea80372cf56e83c001d3c/.agents/skills/impeccable/reference/craft-floor.md)，逐页查看运行记录、任务计划、消息连接、技能、管家，以及新对话、目录与引用菜单。

本轮采用公开指导进行人工代码与渲染复审，没有运行其检测器、双评审工作流或给出自动质量评分。保留用户要求的玻璃视觉，优先保证操作层的文字与边界清楚。

## 修正结果

| 问题 | 对应改变 |
| --- | --- |
| 顶栏标题与目录重叠 | 标题和目录归为同一行，再与工具区分配宽度，长文本截断并保留完整提示 |
| 同一目录出现三次 | 新对话下方收成一条工作目录选择栏，附加目录收在菜单里，旁边直接显示终端入口 |
| 引用菜单透出欢迎标题、离输入框太远 | 菜单移到顶层portal，按实际菜单高度定位；清晰底色、小字号和单行分类，文件根目录的无效“/”说明移除 |
| 新对话找不到工具与终端 | 未发送消息时也显示工具；终端与模型分工不再依赖已有对话才能发现 |
| 没有/goal入口 | /goal作为现有目标控制器的别名，命令菜单可发现；需要时先建立会话，沿用暂停、继续、结束与状态能力 |
| 推理档位命名与识别落后 | 默认展示补低档；当前GPT型号支持极高选项，供应商明确档位优先；显示统一为低、中等、高、极高 |
| 功能页面透明、字号不一致 | 提高功能页面的实底比例与正文对比，统一13px操作字号，保留外层玻璃材质 |
| Web终端只是不可用提示 | 接入真实PTY和xterm.js，在工作区内使用，不需要跳到系统Terminal应用 |

## 内置终端

使用 [xterm.js](https://xtermjs.org/) 6.0.0 与 FitAddon 0.11.0，MIT许可随包保留。组件按需加载。网页与桌面共用既有TerminalSessionManager及会话归属，支持目录选择、输入、实时输出、调整尺寸、清屏、停止和重新打开。隐藏面板保留进程；停止或应用退出会结束进程。重启后的历史记录不冒充仍存活的PTY。

终端接口及输出只给本机用户连接；不把新的终端输出扩大到只有聊天读取权限的远端客户端。模型使用的命令工具与用户交互终端保持各自入口。

- /goal通过真实服务启动，显示目标内容与时间，并可从目标条结束。新对话命令使用创建得到的明确会话身份，避免向空路径发送。
- 资源菜单、目录条、标题、工具和推理标签已进行Web核对。五个非聊天页面逐页截图复审，没有把静态截图算作所有业务场景已验证。
- 命令、推理和引用定向31项检查通过；终端、WS范围及相关控制40项检查通过。随后针对性增量检查与类型核对随最终包记录；数字存在重叠，不累计为独立功能覆盖量。
- 268中的主页面和管家改造继续有效：所选子模型实际在授权隔离仓库写入，原始两个测试仓库保持不变。初始审批测试失败仍单独保留。

## 最终交互修正

- 资源菜单的尺寸观察原先把内容高度回写为最大高度，会从114px逐次缩到84px。最大高度现只由可用视口决定；同一菜单两次实测高度均为124.4px。
- 点击发送会先触发菜单的外部点击关闭，把斜杠命令误当作普通消息。发送控件现保留命令选择，Esc等明确取消行为不变。新对话输入`/goal`后点击发送，实际出现目标、计时、暂停和结束按钮；结束后目标条消失。
- 新对话点击终端、选择目录、等待连接、输入`pwd`的完整路径通过，返回所选目录。点击停止后显示“已停止”。
- 最终渲染构建、类型检查和271完整签名包通过。只补上述发现问题的操作路径，未重复无关全量测试。
- 正式271原生界面确认：运行记录作为主页面显示，内容底色清楚；刷新后更新时间变化；管家创建表单显示仓库权限与主／子模型选择；终端入口打开目录选择。回到原聊天后草稿仍在。终端命令执行的证据来自隔离Web实例，未在正式用户目录执行测试命令。
- 安装前保护768个配置、草稿及会话相关文件，安装后无缺失；模型与草稿文件未变化。正常应用保持单实例运行，测试服务与测试终端在收尾时停止。
